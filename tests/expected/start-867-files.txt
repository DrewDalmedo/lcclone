# 867. Transpose Matrix

**Difficulty:** Easy · **Tags:** array, matrix, simulation

`matrix` has `m` rows of `n` integers each. Return its **transpose**: the
matrix with `n` rows of `m` integers, where the number in row `i` and column
`j` of `matrix` moves to row `j` and column `i`.

In other words, the first column of `matrix` becomes the first row of the
answer, the second column the second row, and so on.

**Example 1:**

```
Input: matrix = [[1,2],[3,4]]
Output: [[1,3],[2,4]]
```

**Explanation:** The columns [1,3] and [2,4] become the rows.

**Example 2:**

```
Input: matrix = [[5,6,7]]
Output: [[5],[6],[7]]
```

**Explanation:** One row becomes one column.

**Example 3:**

```
Input: matrix = [[1],[2]]
Output: [[1,2]]
```

**Explanation:** One column becomes one row.

## Constraints

- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 1000`
- `1 <= m * n <= 10^5`
- `-10^9 <= matrix[i][j] <= 10^9`
