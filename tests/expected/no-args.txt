usage: lc <command> [options] [arguments]

lc is an offline LeetCode-style practice tool. It lists problems,
shows their statements, sets up a directory for your solution, and
judges your solution against the problem's test cases.

Commands:
  list      List problems, filtered by difficulty, tags and status
  random    Pick a random problem, filtered like 'lc list'
  show      Show a problem's statement and examples
  start     Set up a problem's directory and open your editor
  test      Run your solution on the examples and your own cases
  submit    Run your solution on every case of the problem
  stats     Show how many problems you have solved
  check     Check problem packs (for authors)
  help      Show help for lc or for one command
  version   Print the version

Run 'lc help <command>' for the options of a command. Every command
takes --json for machine-readable output (see docs/json.md).

Environment:
  LC_PROBLEMS  directory of problem packs (default:
               $XDG_DATA_HOME/lcclone/problems, else
               ~/.local/share/lcclone/problems, then the installed ones)
  LC_WORKSPACE directory for your solutions (default: the config's
               workspace, else ~/lc)
  LC_CONFIG    the config file (default:
               $XDG_CONFIG_HOME/lcclone/config, else
               ~/.config/lcclone/config)
  CC, CXX      the C and C++ compilers, unless the config sets cc or cxx
               (default: cc, c++)
  LC_CSTD, LC_CXXSTD
               the C and C++ standards (default: the config's cstd and
               cxxstd, else c11 and c++11)
  VISUAL, EDITOR
               editor for 'lc start', unless the config sets editor
               (default: vi)
  PAGER        pager for 'lc show' (default: less, then more)
  NO_COLOR     if set and not empty, --color=auto never uses colour
  COLUMNS      width to wrap text at (default: the terminal's, or 80)
  XDG_CACHE_HOME
               builds go in $XDG_CACHE_HOME/lcclone (default:
               ~/.cache/lcclone)
  XDG_DATA_HOME
               your progress and submissions go in
               $XDG_DATA_HOME/lcclone (default: ~/.local/share/lcclone)

Exit status: 0 on success or Accepted, 1 for any other verdict (or a
pack 'lc check' fails), 2 for Compile Error, 3 on a usage error, an
unknown problem or any other failure, and 130 when ^C stopped a run.
