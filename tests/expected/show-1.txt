1. Two Sum
Difficulty: Easy
Tags: array, hash-table

You are given an array of integers nums and a value target. Find two different
positions in nums whose values add up to target, and return those positions.

Every input has exactly one such pair, and a position cannot be paired with
itself. Return the two positions in either order.

Example 1:
  Input: nums = [6,3,1,8], target = 11
  Output: [1,3]
  Explanation: 3 + 8 = 11, and those values sit at positions 1 and 3.

Example 2:
  Input: nums = [-4,-4], target = -8
  Output: [0,1]

Constraints

  - 2 <= nums.length <= 5000
  - -10^6 <= nums[i], target <= 10^6
  - Exactly one pair adds up to target.

Follow-up

Checking every pair with two nested loops takes O(n^2) time. Can you find the
answer in a single pass over nums?
