# Sorting the Sentence.

@example The digits say Zoe comes first and cat last. Sorting the words alphabetically would give another order.
"cat4 the3 Zoe1 fed2"
=> "Zoe fed the cat"

@example A single word only loses its digit.
"Stop1"
=> "Stop"

@example A word can occur more than once; each copy goes back to its own place.
"no3 Oh1 no2"
=> "Oh no no"

# The shortest input.
"a1"
=> "a"

# Nine words of one letter, in reverse order.
"i9 h8 g7 f6 e5 d4 c3 b2 a1"
=> "a b c d e f g h i"

# Already in order.
"We1 are2 home3"
=> "We are home"

# Alphabetical order (Fig banana pear), order ignoring case (banana Fig
# pear) and order of length (Fig pear banana) are all wrong.
"banana3 pear1 Fig2"
=> "pear Fig banana"

# Upper and lower case anywhere in a word stay as they are.
"sTaY3 mUsT2 yOu1"
=> "yOu mUsT sTaY"

# The same word three times, at different places.
"la4 Tra1 la2 la3"
=> "Tra la la la"

# Two words that differ only in case.
"Ab2 aB1"
=> "aB Ab"

# Digit 9 first and digit 1 last, with words of several lengths.
"gone9 It1 was2 here3 a4 minute5 ago6 and7 now8"
=> "It was here a minute ago and now gone"
