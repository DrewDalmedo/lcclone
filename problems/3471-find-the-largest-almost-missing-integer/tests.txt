# Find the Largest Almost Missing Integer.

@example The windows are [5,8], [8,1] and [1,6]: 5 and 6 are each in one, 8 and 1 in two.
[5,8,1,6]
2
=> 6

@example One window holds everything, so each value counts once; the two 12s are under the same window.
[12,3,12]
3
=> 12

@example Both windows hold a 6 and a 1.
[6,1,6]
2
=> -1

# One element: the answer is that element, 0 included.
[0]
1
=> 0

[50]
1
=> 50

# k = 1: a value counts once per copy, so a repeated value never
# qualifies.
[50,3,50,3]
1
=> -1

[9,4,9,7,1]
1
=> 7

# k = n: copies don't matter.
[5,5,5]
3
=> 5

[2,50,7,50]
4
=> 50

# Both ends are counted once; the larger is at the start, then at the
# end. Inner values are in two or more windows, however large.
[40,1,2,3,10]
3
=> 40

[8,50,49,9]
2
=> 9

# Equal ends: each is in the first and the last window.
[17,48,50,17]
3
=> -1

# The first value also occurs inside, so only the last one qualifies.
[6,2,6,9,1]
2
=> 1

# The answer is 0, which is not "nothing found".
[0,5,5]
2
=> 0

# The answer is the last element, 50.
[1,7,50]
2
=> 50
