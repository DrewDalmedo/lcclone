# Maximum Number of Operations With the Same Score I.

@example The first three operations score 10 each; the fourth would score 5 + 2 = 7.
[4,6,7,3,1,9,5,2]
=> 3

@example The second operation would score 12, not 7, so you stop after one, though 3 + 4 is 7 again.
[2,5,6,6,3,4]
=> 1

@example Both pairs score 16; the lone 9 at the end is never taken.
[8,8,10,6,9]
=> 2
