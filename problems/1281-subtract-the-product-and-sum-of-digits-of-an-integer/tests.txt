# Subtract the Product and Sum of Digits of an Integer.

@example The digits 3, 5 and 7 multiply to 105 and add up to 15.
357
=> 90

@example The 0 makes the product 0; the digits add up to 6.
1203
=> -6

@example A single digit is both the product and the sum.
6
=> 0

# The smallest n.
1
=> 0

# A trailing zero.
10
=> -1

# Only ones: the product stays 1 while the sum grows.
11
=> -1

11111
=> -4

# The product equals the sum.
123
=> 0

# A product of 729, too big for a char.
999
=> 702

# Products above 32767, too big for a 16-bit short; 99999 gives the
# largest answer.
99998
=> 52444

99999
=> 59004

# Several inner zeros.
90909
=> -27

# The smallest answer: a zero and the largest digit sum.
99990
=> -36

# The upper bound, the only n with six digits.
100000
=> -1
