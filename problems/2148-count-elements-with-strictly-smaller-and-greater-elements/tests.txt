# Count Elements With Strictly Smaller and Greater Elements.

@example The minimum is -1 and the maximum 9; both 4s and the 0 lie strictly between them.
[4,-1,9,4,0]
=> 3

@example Only 7 has a smaller value (3) and a greater one (10); the copies of 3 and 10 do not count.
[3,10,3,10,7]
=> 1

@example All the values are equal, so none has anything strictly below it.
[5,5,5]
=> 0

# A single element.
[42]
=> 0

# Two different elements: one is the minimum, the other the maximum.
[1,2]
=> 0

# The extremes of the range, with 0 between them.
[-100000,0,100000]
=> 1

# Values close to the top of the range.
[100000,99999,100000]
=> 0

# All positive: a minimum that starts at 0 would count too much.
[5,6,7]
=> 1

# All negative: a maximum that starts at 0 would count too much.
[-7,-3,-5,-9]
=> 2

# Several copies of the minimum, the maximum and a middle value.
[1,1,4,4,4,9,9]
=> 3

# Only two distinct values, each several times.
[-2,8,8,-2,8,-2]
=> 0

# The counted elements are the first and the last.
[6,1,9,6]
=> 2

# Copies of both extremes around one middle value.
[-100000,-100000,5,100000,100000]
=> 1
