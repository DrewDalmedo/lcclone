# Count Values With Equally Spaced Occurrences I.

@example 10 sits at indices 1, 4 and 7, three apart each time. 6 is also written three times, at 2, 3 and 6, but those are 1 and then 3 apart; 3 and 2 are written once.
[3,10,6,6,10,2,6,10]
=> 1

@example 12 sits at indices 0, 1 and 2, 40 at 3, 5 and 7, and 15 at 4, 6 and 8: three values, each counted once.
[12,12,12,40,15,40,15,40,15]
=> 3

@example 21 is written four times, so it doesn't count, although its first three copies are two apart; the copies of 8, at 1, 3 and 6, are 2 and then 3 apart.
[21,8,21,8,21,21,8]
=> 0

# The shortest array, one value three times in a row.
[1,1,1]
=> 1

# No value repeats.
[3,1,2]
=> 0

# The largest value, starting at index 0; 1 is written twice.
[100,1,100,1,100]
=> 1

# Uneven gaps both ways round: 7 at 0, 1, 3 and 9 at 4, 6, 7; 4 twice.
[7,7,4,7,9,4,9,9]
=> 0

# 5 at 0, 2 and 6: the first and last copies are an even distance apart,
# but the middle one is not halfway between them.
[5,1,5,2,3,4,5]
=> 0

# The widest spacing for seven entries: 9 at 0, 3 and 6.
[9,1,2,9,3,4,9]
=> 1

# 2 is written four times, evenly spaced, so it doesn't count; 9 at 1, 3
# and 5, between the copies of 2, does.
[2,9,2,9,2,9,2]
=> 1

# Two values count, each once, not once per copy.
[3,3,3,8,8,8,1,1]
=> 2

# One value five times.
[6,6,6,6,6]
=> 0
