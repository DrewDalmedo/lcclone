# Subarrays Distinct Element Sum of Squares I.

@example Three one-number slices give 1 each; [3,9] gives 4, [9,9] gives 1 and [3,9,9] gives 4.
[3,9,9]
=> 12

@example All three numbers differ, so each slice's variety is its length: 3*1 + 2*4 + 1*9.
[8,2,6]
=> 20

@example Every slice longer than one number holds both 4 and 7, so 4 slices give 1 and 6 give 4.
[4,7,4,7]
=> 28

# A single number, at the top of the range (a table of 100 entries indexed
# by value is one too short).
[100]
=> 1

# Both ends of the value range.
[1,100]
=> 6

# All equal: every slice has variety 1, so the answer is n * (n + 1) / 2.
[6,6,6,6,6]
=> 15

# A value comes back after others: the whole slice has variety 3, not 4.
[2,9,5,2]
=> 43

# Two values alternating: every slice but the single numbers has variety 2.
[1,100,1,100,1,100]
=> 66

# Long runs: only the 9 slices that cross from the 3s to the 8s have
# variety 2.
[3,3,3,8,8,8]
=> 48

# Values 64 apart (5 and 69, 36 and 100) are all different; a 64-bit mask
# indexed by value mod 64 would merge them.
[5,69,100,36]
=> 50

# Values of 64 and above, repeated.
[64,99,1,64,99]
=> 75
