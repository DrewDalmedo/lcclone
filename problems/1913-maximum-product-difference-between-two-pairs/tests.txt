# Maximum Product Difference Between Two Pairs.

@example Plus pair 10 and 8, minus pair 1 and 3: 80 - 3 = 77.
[3,10,1,6,8]
=> 77

@example All four entries must be used, and both products are 49.
[7,7,7,7]
=> 0

@example Plus pair 11 and 11, minus pair 2 and 2: 121 - 4 = 117.
[6,2,11,2,11,4]
=> 117

# Exactly four entries, all different.
[4,1,3,2]
=> 10

# 1 and 10^4, each twice: the largest answer there is, which still fits
# in an int.
[1,10000,1,10000]
=> 99999999

# All equal, at the top bound.
[10000,10000,10000,10000,10000]
=> 0

# A single largest value at index 0, then a single smallest value at
# index 0: neither may be used twice.
[9,1,7,3]
=> 60

[1,7,3,9]
=> 60

# Sorted up, and sorted down.
[1,2,3,4,5,6]
=> 28

[9,8,7,6,5]
=> 42

# The largest value twice, side by side at the end; the smallest value
# twice, side by side at the start.
[3,5,4,8,8]
=> 52

[2,2,9,5,7]
=> 59

# The largest value three times.
[6,6,6,1,2]
=> 34

# The largest value first and the smallest value last.
[50,10,20,30,40,5]
=> 1950
