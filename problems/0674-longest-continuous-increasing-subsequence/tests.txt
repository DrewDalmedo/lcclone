# Longest Continuous Increasing Subsequence.

@example 2, 4, 8 climbs. 3 is smaller than 8, so a new block starts there.
[6,2,4,8,3,9]
=> 3

@example Equal neighbours can't share a block, so the best is 5, 7 in the middle.
[5,5,7,7]
=> 2

@example 1, 2, 3, 12 increases but skips elements; every block of three has a fall in it.
[1,10,2,11,3,12]
=> 2

# A single element.
[-1000000000]
=> 1

# Falling all the way: no two neighbours climb, and the answer is 1, not 0.
[9,4,0,-3]
=> 1

# All equal.
[-6,-6,-6,-6]
=> 1

# The whole array climbs, up to the last element.
[-5,-2,0,1,7,30]
=> 6

# The longest block starts at index 0.
[1,2,3,4,0,5,6]
=> 4

# The longest block ends at the last element.
[3,1,4,0,2,5,8,9]
=> 5

# The longest block is in the middle.
[9,1,3,5,7,2,6]
=> 4

# Equal neighbours split the blocks: counting them as a climb gives 7.
[1,2,2,3,4,4,5]
=> 3

# Three blocks tie for the longest.
[4,5,1,2,0,3]
=> 2

# The extreme values next to each other.
[1000000000,-1000000000,1000000000]
=> 2

# A climb across zero.
[-3,-1,0,2,1]
=> 4
