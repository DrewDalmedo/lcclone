# Count Number of Pairs With Absolute Difference K.

@example Each of the two 5s pairs with the 8 and with the 2, and the 8 also pairs with the 11.
[5,8,2,5,11]
3
=> 5

@example Both 9s are 8 more than the 1, one before it and one after it.
[9,1,9]
8
=> 2

@example No two values are 5 apart.
[10,20,30]
5
=> 0

# A single value has nothing to pair with.
[50]
1
=> 0

# Equal values are never a pair.
[6,6,6,6]
1
=> 0

# The larger value comes first.
[7,4]
3
=> 1

# k is larger than any gap.
[1,2,3,4]
10
=> 0

# The extremes: each 100 pairs with each 1 when k = 99.
[100,1,1,100,50]
99
=> 4

# 1 - 99 and 100 + 99 fall outside the values; 1 and 100 are the only pair.
[1,50,100]
99
=> 1

# Runs of equal values on both sides multiply: 3 * 2.
[2,2,2,3,3]
1
=> 6

# 3 has partners on both sides, 1 below and 5 above: 2 * 2 + 2 * 1.
[1,3,5,3,1]
2
=> 6

[4,7,4,7,7]

=> 6
