# Sort Array by Increasing Frequency.

@example The single 0 comes first, then the two 7s, then the three 4s.
[4,7,4,0,7,4]
=> [0,7,7,4,4,4]

@example 9 and 1 occur once each, so the larger, 9, comes first; then 5 and -2, twice each.
[5,-2,9,-2,5,1]
=> [9,1,5,5,-2,-2]

@example Every count is 1, so the values go from largest to smallest.
[3,8,-1]
=> [8,3,-1]

# A single value.
[-100]
=> [-100]

# All values equal.
[6,6,6,6]
=> [6,6,6,6]

# Both bounds and 0, once each: the largest first.
[-100,0,100]
=> [100,0,-100]

# -100 once and 100 twice: the count decides, whatever the values.
[100,-100,100]
=> [-100,100,100]

# Equal counts among negative values, 0 and positive values.
[-5,0,-5,3,0,3,-1]
=> [-1,3,3,0,0,-5,-5]

[-7,-30,-7,-30,-1]
=> [-1,-7,-7,-30,-30]

[-1,1,-1,1]
=> [1,1,-1,-1]

# The order by count is not the order by value.
[1,1,1,99,-99,-99]
=> [99,-99,-99,1,1,1]

[-60,40,40,-60,40,-80]
=> [-80,-60,-60,40,40,40]

# Counts that tie and counts that differ in one input.
[2,-3,2,8,-3,8,8,5]
=> [5,2,2,-3,-3,8,8,8]

# The bound 100 is the most frequent value.
[100,-3,100,50,100,-100,100]
=> [50,-3,-100,100,100,100,100]
