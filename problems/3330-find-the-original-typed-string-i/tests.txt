# Find the Original Typed String I.

@example s was "zoomm" itself, or "zomm" with its o echoed, or "zoom" with its m echoed.
"zoomm"
=> 3

@example No letter sits next to a copy of itself, so nothing was echoed: only "kayak" works.
"kayak"
=> 1

@example s began with 1, 2, 3, 4 or 5 b's, followed by the x.
"bbbbbx"
=> 5

# A single letter.
"q"
=> 1

# Two equal letters: "zz", or "z" echoed once.
"zz"
=> 2

# Two different letters.
"az"
=> 1

# The same letter in several places, never side by side.
"abacada"
=> 1

# Two blocks of the same letter: "aabaa", "abaa" or "aaba".
"aabaa"
=> 3

# The echo lengthened one block only, so the blocks' choices add up
# (1 + 1 + 1 + 1), they don't multiply.
"ccddee"
=> 4

"pppqqqrrr"
=> 7

# A block at the very end.
"xyzzzz"
=> 4

# Blocks at both ends, and t in two of them: 1 + 1 + 3 + 1 + 1.
"tteeeesstt"
=> 7

# The longest word, one letter throughout: s has 1 to 100 w's.
"wwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwwww"
=> 100

# The longest word with no two neighbours equal.

=> 1
