# Form Smallest Number From Two Digit Arrays.

@example No digit is in both lists; 2 and 5 are their smallest digits, so 25.
[6,2,8]
[9,5]
=> 25

@example 4 is in both lists, and one digit beats any two-digit number.
[7,4,9]
[8,4]
=> 4

@example Nothing is shared; the smaller minimum, 3, comes from nums2 and goes first.
[9,6]
[8,3,7]
=> 36

# One digit in each list, the same digit.
[5]
[5]
=> 5

# One digit in each list, different: 89 is the largest possible answer,
# whichever list holds the 8.
[8]
[9]
=> 89

[9]
[8]
=> 89

# The shared digit is the smallest of neither list, but 6 is less than 12.
[1,6]
[2,6]
=> 6

# Three shared digits; the smallest of them comes last in both lists.
[9,7,5,3]
[5,7,2,3]
=> 3

# The only shared digit is 9, the largest digit, and it still beats every
# two-digit number.
[3,9]
[9,6]
=> 9

# Equal minimums are a shared digit: 4, not 44.
[4,6]
[7,4]
=> 4

# The smallest digit of nums1 is at its end.
[9,8,7,3]
[6,5,4]
=> 34

# A list of all nine digits shares every digit of the other list.
[3,9,1,7,5,2,8,4,6]
[8,6,7]
=> 6

[2,6]
[9,8,7,6,5,4,3,2,1]
=> 2

# The smallest possible answers.
[3,1]
[1,2]
=> 1

[1,5]
[9,2]
=> 12

# Random cases from gen.c (lc check --regen makes them).
@gen 2 small
[6]
[4]
=> 46

@gen 3 small
[4,6,8]
[7,3,5]
=> 34

@gen 4 small
[8]
[2,4,6]
=> 28

[9,2]
[3,6,8]
=> 23

@gen 6 small
[7,2,4,5,6,8,3,9]
[8,2]
=> 2

@gen 7 small
[7,3]
[8,4,6]
=> 34

@gen 8 small
[7,5,6]
[9,3,5,8]
=> 5

@gen 3
[8,4,1,3,2]
[7,9]
=> 17

@gen 12
[3]
[4,6,7,5,9,8,2,1]
=> 13
