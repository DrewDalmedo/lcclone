title: Smallest Even Multiple
difficulty: easy
tags: math, number-theory
signature: int smallestEvenMultiple(int n)
---
Write down the multiples of the positive integer `n` from the smallest up:
`n`, then `2 * n`, then `3 * n`, and so on. Return the first number on that
list that is even.

The list holds only positive multiples, so `0` is never on it, and it starts
with `n` itself.

@examples

## Constraints

- `1 <= n <= 150`
