# Generate Tag for Video Caption.

@example The first word loses its capital, every later word gets one, and RIVER keeps only its first capital.
"Morning run by the RIVER"
=> "#morningRunByTheRiver"

@example The spaces only separate words, so "sunset" is the first word and gets no capital.
"   sunset   Over the BAY "
=> "#sunsetOverTheBay"

@example One-letter words: the first one stays a small letter, the later ones become capitals.
"x Y z"
=> "#xYZ"

# A single capital as the only word.
"Q"
=> "#q"

# No letters at all: the tag is the # alone.
" "
=> "#"

# Words in capitals keep only their first capital, and the first word none.
"BIG NEWS TODAY"
=> "#bigNewsToday"

# Mixed case inside words, and trailing spaces that add nothing.
"mIxEd cAsE wOrDs   "
=> "#mixedCaseWords"

# A single leading space: the first word is still lowercased.
" Go Team"
=> "#goTeam"

# 99 letters: the tag is exactly 100 characters, nothing is cut.
"programming programming programming programming programming programming programming programming programming"
=> "#programmingProgrammingProgrammingProgrammingProgrammingProgrammingProgrammingProgrammingProgramming"

# 100 letters: the last letter is cut.
"Basketball Basketball Basketball Basketball Basketball Basketball Basketball Basketball Basketball Basketball"
=> "#basketballBasketballBasketballBasketballBasketballBasketballBasketballBasketballBasketballBasketbal"

"understandable understandable understandable understandable understandable understandable understandable kept"

# 19 leading spaces and 120 letters: the cut applies to the tag, not to the
# caption, so 99 letters remain.

"                                                                                                                                                      "
