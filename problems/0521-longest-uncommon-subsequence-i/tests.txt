# Longest Uncommon Subsequence I. -1 means no string is a subsequence of
# exactly one of the two.

@example "planet" is a subsequence of itself, and it is too long, by a letter, to be one of "plant". No 7-letter string is a subsequence of either.
"plant"
"planet"
=> 6

@example The same letters in another order. A 5-letter subsequence of "thing" can only be "thing" itself, so "night" is a subsequence of "night" alone. No 6-letter string is a subsequence of either.
"night"
"thing"
=> 5

@example The strings are identical, so a string is a subsequence of one of them exactly when it is a subsequence of the other.
"echo"
"echo"
=> -1

# Single letters, the same.
"q"
"q"
=> -1

# Single letters, different.
"x"
"y"
=> 1

# A letter, and the same letter twice.
"m"
"mm"
=> 2

# b is a prefix of a: comparing only the first 2 letters finds no
# difference.
"stone"
"st"
=> 5

# a is a prefix of b.
"ab"
"abcd"
=> 4

# a is a suffix of b.
"ring"
"string"
=> 6

# The same length, one letter apart.
"cold"
"colt"
=> 4

# The longer string comes second, then first.
"kiwi"
"watermelon"
=> 10

"abcdefg"
"xyz"
=> 7
