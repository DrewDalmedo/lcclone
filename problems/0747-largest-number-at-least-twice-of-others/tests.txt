# Largest Number At Least Twice of Others.

@example 11 is more than twice 5, the largest of the other elements.
[5,2,11,5]
=> 2

@example 30 is the largest element, but 16 doubled is 32.
[30,16,7]
=> -1

@example 40 is exactly twice 20, which is enough. Its index is 0.
[40,0,19,20]
=> 0

# Two elements: any positive value is dominant over a 0.
[1,0]
=> 0

# Two elements: 4 doubled is 8, more than 7.
[7,4]
=> -1

# Exactly twice the runner-up.
[14,28,3]
=> 1

# One less than twice the runner-up.
[27,14,1]
=> -1

# The largest comes first: a runner-up started at nums[0] would be the
# largest element itself.
[12,5,2]
=> 0

# The largest comes last.
[6,1,3,20]
=> 3

# Every other element is 0.
[0,0,1,0]
=> 2

# The runner-up occurs three times.
[4,9,4,4]
=> 1

# When 13 turns up, the old largest, 7, becomes the runner-up, and 14 is
# more than 13.
[7,1,13]
=> -1

# 2 * 65 = 130 doesn't fit in a signed char.
[65,100]
=> -1

# The largest value allowed, against exactly half of it.
[50,0,100]
=> 2

# 50 elements: the runner-up, 50, is the last one, and 99 falls short of
# 100.
[0,7,14,21,28,35,42,49,6,13,20,27,34,99,48,5,12,19,26,33,40,47,4,11,18,25,32,39,46,3,10,17,24,31,38,45,2,9,16,23,30,37,44,1,8,15,22,29,36,50]
=> -1
