# Count Elements With Maximum Frequency.

@example 4 and 8 are played three times each, more than any other song, so the hits account for 3 + 3 = 6 entries.
[4,8,4,6,8,4,8,2]
=> 6

@example Only 12 is played twice; every other song once.
[12,40,12,33]
=> 2

@example Every song is played once, so all three are hits.
[15,6,88]
=> 3

# A single entry.
[100]
=> 1

# Every entry is the same song.
[5,5,5,5,5]
=> 5

# The largest number, 100, is the hit: a table of 100 counts indexed by
# the number has no slot for it.
[100,1,100,1,100]
=> 3

# Three songs tie at two plays each, never next to each other.
[3,1,2,3,1,2,9]
=> 6

# Songs played fewer times than the hits don't count.
[2,2,2,7,7,7,9,9,1]
=> 6

# One hit among songs played once.
[10,20,30,40,20]
=> 2

# The hit's plays are never next to each other, while another song's are:
# the longest run of equal neighbours is not the play count.
[6,6,4,9,4,9,4]
=> 3
