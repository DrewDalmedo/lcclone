# Transpose Matrix.

@example The columns [1,3] and [2,4] become the rows.
[[1,2],[3,4]]
=> [[1,3],[2,4]]

@example One row becomes one column.
[[5,6,7]]
=> [[5],[6],[7]]

@example One column becomes one row.
[[1],[2]]
=> [[1,2]]

# A single number.
[[0]]
=> [[0]]

# Not square.
[[-1,0,1],[2,-2,3]]
=> [[-1,2],[0,-2],[1,3]]

[[1,2],[3,4],[5,6],[7,8]]
=> [[1,3,5,7],[2,4,6,8]]

# Square.
[[9,8,7],[6,5,4],[3,2,1]]
=> [[9,6,3],[8,5,2],[7,4,1]]

# Extreme values.
[[1000000000,-1000000000]]
=> [[1000000000],[-1000000000]]
