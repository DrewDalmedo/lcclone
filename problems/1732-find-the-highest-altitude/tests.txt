# Find the Highest Altitude.

@example The posts stand at 0, 3, 2, 6, 0 and 2.
[3,-1,4,-6,2]
=> 6

@example Every post after the start is lower than it: they stand at -2, -10, -5 and -4.
[-2,-8,5,1]
=> 0

@example The posts stand at 0, 1, 2, 3, 1 and 6, so the highest is the last one.
[1,1,1,-2,5]
=> 6

# One change, upward.
[7]
=> 7

# One change, downward: the start is the highest post.
[-7]
=> 0

# A level trail.
[0,0,0]
=> 0

# A climb, then a descent: the answer is not the final altitude, 3.
[5,5,-3,-4]
=> 10

# Changes add up: the answer is neither the largest change, 4, nor the sum
# of the climbs, 12.
[4,-1,4,-1,4]
=> 10

# Several small climbs end higher than one big one.
[9,-9,2,2,2,2,2]
=> 10

# Coming back to an earlier peak doesn't change the answer.
[6,-6,6,-6]
=> 6

# A deep drop first, then a climb above the start.
[-50,30,30]
=> 10

# Back up to exactly 0, never above it.
[-3,1,2,-5]
=> 0
