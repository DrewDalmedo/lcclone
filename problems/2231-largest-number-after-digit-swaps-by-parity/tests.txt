# Largest Number After Digit Swaps by Parity.

@example The even digits 2 and 8 trade places; the odd digits 9 and 3 are already in the best order.
2938
=> 8932

@example The odd digits 1, 3, 5 fill the first, second and last places as 5, 3, 1, and 4 moves ahead of 0.
13045
=> 53401

@example 5 is the only odd digit, so it stays last. Sorting all the digits would give 852, but that needs 5 to trade with an even digit.
285
=> 825

# The smallest num.
1
=> 1

# Each digit is alone in its family, so nothing can move (a plain sort would
# give 41).
14
=> 14

# Already the largest: each family falls from left to right.
987654321
=> 987654321

# Only odd digits, or only even digits: a plain descending sort.
13579
=> 97531

24680
=> 86420

# Both families rise from left to right, in irregular places, so most digits
# have to move.
135024689
=> 953864201

# The family is the digit's value, not the parity of its position: sorting
# the even and the odd positions separately would give 594631210.
314159260
=> 956311420

# A zero moves right, past an odd digit.
2074
=> 4270

# Trailing zeros (reversing num into an int would lose them).
13570
=> 75310

4900
=> 4900

# Repeated digits in both families.
11225544
=> 55441122

# 10^9, the only num with 10 digits.
1000000000
=> 1000000000
