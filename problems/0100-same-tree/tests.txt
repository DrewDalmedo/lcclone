# Same Tree. A case is p, then q, each a tree in level order with null for a
# missing child.

@example Both trees hold the same values in the same places.
[8,-3,5,null,12]
[8,-3,5,null,12]
=> true

@example 4 is the right child of 2 in p, but the left child of 2 in q.
[6,2,9,null,4]
[6,2,9,4]
=> false

@example Only the deepest value differs, 7 in p and 1 in q.
[3,8,1,5,null,null,2,7]
[3,8,1,5,null,null,2,1]
=> false

# Both empty.
[]
[]
=> true

# Only q is empty, and p's one value is 0.
[0]
[]
=> false

# Only p is empty, and q's one value is -1.
[]
[-1]
=> false

# One node each, at opposite bounds.
[10000]
[-10000]
=> false

# Equal trees holding 0, -1 and both bounds.
[0,-1,10000,null,-10000]
[0,-1,10000,null,-10000]
=> true

# The same preorder without null markers: 2, 1, 3.
[2,1,3]
[2,1,null,3]
=> false

# The same inorder without null markers: 1, 2, 3.
[2,1,3]
[1,null,2,null,3]
=> false

# The same rows once the gaps are dropped: 5, then 7 9, then 4.
[5,7,9,null,null,4]
[5,7,9,4]
=> false

# The same values in other places, so sums and XORs agree.
[10,20,30,40]
[10,20,40,30]
=> false

# q is p with one more leaf.
[4,9,1]
[4,9,1,null,null,6]
=> false

# Joined without separators, both read 115.
[11,5]
[1,15]
=> false

# Every value equal, different shapes.
[2,2,null,2]
[2,null,2,null,2]
=> false

# With -1 as the marker for a missing child, these two would read alike.
[4,7,-1]
[4,7,null,-1]
=> false

# The same with 0 as the marker.
[3,8,0]
[3,8,null,0]
=> false

# The same with the lower bound as the marker.
[2,6,-10000]
[2,6,null,-10000]
=> false
