# Calculate Amount Paid in Taxes. compare defaults to float 1e-5 for a double.

@example The first 4 dollars are taxed at 10% (0.40), the next 5 at 30% (1.50) and the last 3 at 5% (0.15).
[[4,10],[9,30],[20,5]]

=> 2.05

@example All 3 dollars fall in the first bracket, which taxes them at 40%.
[[6,40],[100,0]]
3
=> 1.2

@example No income, no tax.
[[10,25]]
0
=> 0.0

# A single bracket taxing the largest income at 100%.
[[1000,100]]
1000
=> 1000.0

# The smallest taxable amount: one dollar at 1%.
[[1,1]]
1
=> 0.01

# The income ends exactly on a bound, so the next bracket takes nothing.
[[5,20],[10,40],[15,60]]

=> 3.0

# The income ends inside the first bracket.
[[50,15],[60,90]]

=> 1.05

# Every rate is 0%.
[[1,0],[1000,0]]
1000
=> 0.0

# Rates fall as well as rise; each bracket is taxed on its width, not on its bound.
