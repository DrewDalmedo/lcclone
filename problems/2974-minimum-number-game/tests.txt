# Minimum Number Game.

@example The first round takes 1 and 3 and appends 3, then 1; the second takes 5 and 8 and appends 8, then 5.
[8,3,5,1]
=> [3,1,8,5]

@example Copies are separate elements: the first round takes both 2s, the second two of the three 6s, and the third the last 6 and the 9.
[6,2,6,6,2,9]
=> [2,2,6,6,9,6]

@example A single round, in which 40 goes in before 7.
[7,40]
=> [40,7]

# The smallest input, two equal values.
[1,1]
=> [1,1]

# Both bounds, in either order.
[100,1]
=> [100,1]

[1,100]
=> [100,1]

# Already ascending: each neighbouring pair is swapped, starting with the
# first two.
[1,2,3,4,5,6]
=> [2,1,4,3,6,5]

# Descending: the answer is not the input reversed.
[10,9,8,7]
=> [8,7,10,9]

# All equal.
[5,5,5,5]
=> [5,5,5,5]

# Three copies of 4: the second round takes the last copy together with 9.
[4,9,4,4]
=> [4,4,9,4]

# Each round takes two equal values.
[3,1,3,1]
=> [1,1,3,3]

# The largest value three times.
