# Count Dominant Indices.

@example 6 beats 18 / 4 = 4.5 and 9 beats 7 / 2 = 3.5, while 2 is below 16 / 3 and 3 is below 4.
[6,2,9,3,4]
=> 2

@example After 5 the mean is (7 + 3) / 2 = 5, a tie, so only 7, which beats 3, is dominant.
[5,7,3]
=> 1

@example Each element is larger than everything after it; the last index never counts.
[9,8,7,6]
=> 3

# A single element: its index is the last one.
[7]
=> 0

# Two elements: equal, then decreasing.
[5,5]
=> 0

[6,5]
=> 1

# All equal, at the largest value.
[100,100,100,100,100]
=> 0

# Strictly increasing: never dominant. (Dividing by n - i instead of
# n - 1 - i would make 4 beat 5 / 2.)
[1,2,3,4,5]
=> 0

# A mean of 3.5: 4 is above it (rounding 3.5 up to 4 would lose it),
# 3 is below it.
[4,2,5]
=> 1

[3,2,5]
=> 0

# A mean of 11 / 3, about 3.67: 4 is above it (rounding the mean to the
# nearest whole number, 4, would lose it); the last 4 ties with 4.
[4,3,4,4]
=> 1

# The mean after 5 is exactly 20 / 4 = 5; only 9 counts.
[5,1,9,4,6]
=> 1

# 5 beats the mean 8 / 3 though the next element is larger.
[5,6,1,1]
=> 2

# One big value at the end pulls the means up; 50 still beats 102 / 3.
[1,50,1,1,100]
=> 1
