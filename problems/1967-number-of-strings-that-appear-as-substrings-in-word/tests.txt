# Number of Strings That Appear as Substrings in Word.

@example "ana" and "ban" are stretches of "banana"; "nab" is not, and the letters of "bn" are not next to each other.
["ana","nab","ban","bn"]
"banana"
=> 2

@example "pa" turns up twice in "papaya", and each of its two entries counts once; "apa" and "ya" count too, but "yap" doesn't.
["apa","pa","yap","pa","ya"]
"papaya"
=> 4

@example The pattern is longer than the word.
["seashells"]
"sea"
=> 0

# The smallest inputs, not found.
["b"]
"a"
=> 0

# The whole word is found; the word with one more letter runs off its end.
["hell","hello"]
"hell"
=> 1

# Found at the very end and at the very start; "xz" has a letter between.
["yz","wx","xz"]
"wxyz"
=> 2

# Letters in the right order, but not next to each other, don't count.
["tm","eam","tam"]
"team"
=> 1

# Found three times, overlapping, but counted once.
["aa"]
"aaaa"
=> 1

# A search that doesn't step back after a partial match misses both.
["aab","aaab"]
"aaaab"
=> 2

["abac"]
"ababac"
=> 1

# A pattern of 100 letters against a word of 1.
["aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa","a"]
"a"
=> 1

# Equal entries are each counted, found or not.
