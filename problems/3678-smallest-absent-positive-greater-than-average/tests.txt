# Smallest Absent Positive Greater Than Average.

@example The average is 19 / 4 = 4.75. The first whole number above it is 5, which is not in nums.
[6,2,7,4]
=> 5

@example The average is exactly 5. It is missing from nums but not greater than itself, so the answer is 6.
[1,9,3,7]
=> 6

@example The average, -10 / 5 = -2, is below every positive number; 1 and 2 are in nums, 3 is not.
[-8,1,-3,2,-2]
=> 3

# A single entry, the largest allowed: the answer is one more.
[100]
=> 101

# A single entry, the smallest allowed: every positive number is above the
# average, and 1 is missing.
[-100]
=> 1

# The average 30 / 6 = 5 is a missing whole number and must be skipped;
# 6 is present too.
[2,4,6,8,10,0]
=> 7

# Average 3.5, exactly halfway: 4 is above it and missing.
[1,6]
=> 4

# Average 10 / 3 = 3.33..., a fraction below one half: 4 is the answer,
# not 3.
[8,1,1]
=> 4

# A negative entry pulls the average down to 10 / 4 = 2.5; the average of
# the positive entries alone would be 20.
[-50,10,20,30]
=> 3

# Every copy of 9 counts: the average is 28 / 4 = 7, not (9 + 1) / 2.
[9,9,9,1]
=> 8

# Average 1 / 3, between 0 and 1: 1 is present, so 2.
[-3,3,1]
=> 2

# All equal: the answer is above the largest entry.
[5,5,5]
=> 6

# Average -9 / 5: zero and negative numbers are never candidates; 1, 2 and
# 3 are present.
[-20,1,2,3,5]
=> 4
