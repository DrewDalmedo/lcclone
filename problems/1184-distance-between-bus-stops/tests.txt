# Distance Between Bus Stops.

@example Going 0 → 1 → 2 → 3 takes 6 + 1 + 8 = 15; going the other way, 0 → 4 → 3, takes 2 + 3 = 5.
[6,1,8,3,2]
0
3
=> 5

@example Going 3 → 2 → 1 takes 8 + 1 = 9; going the other way, 3 → 4 → 0 → 1, takes 3 + 2 + 6 = 11.
[6,1,8,3,2]
3
1
=> 9

@example Start and destination are the same shelter.
[12,5,9]
2
2
=> 0

# The last stretch is long, so the way through every other shelter wins.
