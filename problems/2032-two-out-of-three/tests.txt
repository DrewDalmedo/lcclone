# Two Out of Three. compare: unordered 0; the expected answers are listed
# in increasing order.

@example 7 is in nums1 and nums2, 2 in nums1 and nums3, and 9 in nums2 and nums3. 4 and 5 are in one list each.
[4,7,4,2]
[7,9]
[2,9,5]
=> [2,7,9]

@example 6 is there three times, but all three are in nums1.
[6,6,6]
[1]
[3,3]
=> []

@example 8 is in all three lists and is returned once; 1 is in nums1 and nums2.
[8,1]
[1,8]
[8]
=> [1,8]

# The smallest lists, all with the same value.
[5]
[5]
[5]
=> [5]

# The smallest lists, all different.
[1]
[2]
[3]
=> []

# Only nums1 and nums2 share values.
[100,50]
[50,100]
[1]
=> [50,100]

# Only nums1 and nums3 share a value, repeated in nums3.
[9,3]
[8]
[9,9,9]
=> [9]

# Only nums2 and nums3 share values.
[1]
[2,3]
[3,2]
=> [2,3]

# Only nums2 and nums3 share values, each repeated in both: still listed once.
[1,2]
[9,9,5,9]
[5,9,9,5]
=> [5,9]

# The bounds 1 and 100.
[1,100]
[100]
[1]
=> [1,100]

# Repeats within one list don't count as several lists.
[42,42,42,42,42,42]
[7,7]
[3]
=> []

# The three lists hold the same values, in other orders and with repeats.
[3,1,2,3]
[2,3,1]
[1,1,2,3]
=> [1,2,3]

# One value in all three lists, one in two, and three in only one.
[10,20,30]
[20,40]
[30,20,50]
=> [20,30]

# No value is shared, though every list repeats its own.
[1,1,2]
[3,3,4,4]
[5,6,6]
=> []
