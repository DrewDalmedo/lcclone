# Minimum Index Sum of Two Lists. compare: unordered 0 accepts the strings
# in any order; the expected answers below list them in list1's order.

@example lamp is first in list1 and bed first in list2, but each sums to 4 (0 + 4 and 4 + 0); chair sums to 2 + 1 = 3.
["lamp","desk","chair","sofa","bed"]
["bed","chair","rug","shelf","lamp"]
=> ["chair"]

@example juice sums to 2 + 2 and milk to 3 + 1: a tie at 4, so both are returned.
["tea","coffee","juice","milk"]
["water","milk","juice"]
=> ["juice","milk"]

@example elm and Elm differ in case, so oak (0 + 2) is the only common string.
["oak","pine","elm"]
["Elm","ash","oak"]
=> ["oak"]

# One string in each list.
["x"]
["x"]
=> ["x"]

# The only common string is last in both lists.
["a","b","c","d"]
["e","f","g","d"]
=> ["d"]

# Common at index 0 of both lists: the sum is 0.
["k","m","n"]
["k","n","m"]
=> ["k"]

# Reversed lists: every string sums to 3.
["p","q","r","s"]
["s","r","q","p"]
=> ["p","q","r","s"]

# The strings at the front of either list lose to one in the middle of both.
["aa","bb","cc","dd","ee","ff"]
["ff","xx","cc","yy","zz","aa"]
=> ["cc"]

# Spaces count: "icecream" and "ice cream " are not "ice cream".
["ice cream","pie","sorbet"]
["icecream","ice cream ","sorbet","ice cream"]
=> ["ice cream"]

# A prefix is not a match: "car" is not in list2, though "cart" and
# "carts" are.
["car","cart","care"]
["ca","carts","care","cart"]
=> ["cart","care"]

# Case counts: only "rose" and "ROSE" are in both lists.
["Rose","rose","ROSE"]
["rOse","ROSE","rose"]
=> ["rose","ROSE"]

# A string of one space, and one of 30 letters.
[" ","abcdefghijklmnopqrstuvwxyzABCD"]
["abcdefghijklmnopqrstuvwxyzABCD"," "]
=> [" ","abcdefghijklmnopqrstuvwxyzABCD"]

# Leading and trailing spaces count: "fig " and " kiwi" are not "fig"
# and "kiwi", so plum (1 + 2) is the only common string.
["fig ","plum"," kiwi"]
["fig","kiwi","plum"]
=> ["plum"]

# Lists of different lengths.
["only"]
["one","two","three","four","only"]
=> ["only"]
