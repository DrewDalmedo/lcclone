# Plus One.

@example 407 + 1 = 408: only the last digit changes.
[4,0,7]
=> [4,0,8]

@example 2899 + 1 = 2900: the two 9s at the end turn into 0s and the 8 before them into a 9.
[2,8,9,9]
=> [2,9,0,0]

@example 999 + 1 = 1000, which has one digit more.
[9,9,9]
=> [1,0,0,0]

# Zero.
