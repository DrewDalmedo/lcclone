# Divide a String Into Groups of Size k.

@example Rows of 4: "sunf", "lowe", then "r" and three copies of fill.
"sunflower"
4
"z"
=> ["sunf","lowe","rzzz"]

@example 6 letters make exactly two rows of 3, so fill is never used.
"pebble"
3
"q"
=> ["peb","ble"]

@example One row of 5 cells holds both letters; fill pads it even though it is a letter of s.
"ox"
5
"o"
=> ["oxooo"]

# The smallest input.
"m"
1
"a"
=> ["m"]

# k = 1: every letter is a row of its own.
"dog"
1
"z"
=> ["d","o","g"]

# k equals the length: one full row.
"river"
5
"y"
=> ["river"]

# k = 2 divides the length.
"toasts"
2
"b"
=> ["to","as","ts"]

# k is one less than the length: the last row has a single letter.
"lamp"
3
"e"
=> ["lam","pee"]

# fill equals the last letters of s; nothing is removed.
"baa"
2
"a"
=> ["ba","aa"]

# One letter in a row of 100 cells: 99 copies of fill.
