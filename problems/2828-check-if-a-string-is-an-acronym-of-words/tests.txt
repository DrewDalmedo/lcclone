# Check if a String Is an Acronym of Words.

@example The opening letters of "paper", "ink" and "eraser" spell "pie".
["paper","ink","eraser"]
"pie"
=> true

@example Three words give three initials, "roy"; "ro" stops one letter short.
["red","orange","yellow"]
"ro"
=> false

@example The initials are "sm"; the same two letters in the other order don't count.
["sun","moon"]
"ms"
=> false

# A single word of one letter: its initials are the whole word.
["q"]
"q"
=> true

["q"]
"z"
=> false

# s is the only word, which has more than one letter.
["hat"]
"hat"
=> false

# s goes on after the initials "dc".
["dog","cat"]
"dce"
=> false

# The last letters of the words; a one-letter word has the same first and
# last letter.
["x","yes","to"]
"xso"
=> false

# Several words start with the same letter: s needs exactly three b's, not
# two.
["bee","bat","bug","owl"]
"bbbo"
=> true

["bee","bat","bug","owl"]
"bbo"
=> false

# Only the first letter is wrong.
["wolf","elk","yak"]
"xey"
=> false
