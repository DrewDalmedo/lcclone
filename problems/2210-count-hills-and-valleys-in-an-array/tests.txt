# Count Hills and Valleys in an Array.

@example The plateaus are 3 / 7,7 / 2 / 5,5,5 / 8. 7,7 is a hill and 2 a valley; 5,5,5 lies between 2 and 8, lower on one side and higher on the other.
[3,7,7,2,5,5,5,8]
=> 2

@example The middle 8, 4 and 8 each turn: two hills and a valley.
[4,8,4,8,4]
=> 3

@example Two plateaus, 6,6,6 and 2,2, each at an end of the trail.
[6,6,6,2,2]
=> 0

# The shortest trails.
[1,2,1]
=> 1

[100,1,100]
=> 1

[5,5,9]
=> 0

# All heights equal.
[7,7,7,7]
=> 0

# Only falling, with flat stretches: no turns.
[9,9,7,7,7,3,3,1]
=> 0

# A flat top counts once: comparing only the elements right next to each
# index misses it, and comparing with <= counts it once per element.
[1,4,4,4,4,2]
=> 1

# A flat valley.
[8,3,3,8]
=> 1

# A flat stretch on the way up is a step, not a turn.
[2,6,6,6,10]
=> 0

# A long first plateau higher than what follows, and a long last one
# lower than what comes before: neither counts.
[9,9,9,9,4,6,1,1,1]
=> 2

# Equal heights that are not adjacent are different plateaus.
[3,1,3,1,3,1]
=> 4
