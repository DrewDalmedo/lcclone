@example First window: 9 and 4 appear twice, 1 once, so 9 + 9 + 4 + 4 = 26. Last window: 9 twice, and of 4, 1 and 6 (once each) 6 ranks next: 9 + 9 + 6 = 24.

@example In [1,5,2] each value appears once, so the two largest, 5 and 2, are kept and the 1 is dropped. The other two windows hold only two distinct values, so all of each counts.
[5,1,5,2,5]

=> [11,7,12]

@example 1 appears three times and 50 twice, so only the 1s are kept, though 50 is larger.

# The smallest input.
[7]
1
1
=> [7]

# x == k: no window can have more than x distinct values, so each x-sum
# is the plain sum of its window.
[5,1,5,2]
2
2
=> [6,6,7]

# k = 1: each window is one element, so the answer is nums itself.
[50,1,25,1]
1
1
=> [50,1,25,1]

# One window of distinct values with x = 1: only the largest counts.
[3,10,6,2]
4
1
=> [10]

# All distinct: each window keeps its x largest values.
[5,1,4,2,3]
3
2
=> [9,6,7]

# Equal counts: the larger value wins, whether it comes first or last in
# the window.
[15,15,40,40,15,15]
4
1
=> [80,80,80]

# Three values tie for two places: the two larger ones are kept.
[1,2,3,3,2,1]
6
2
=> [10]

# x counts distinct values: the three 6s all count, and the tie for second
# place between 2 and 9 goes to 9.
[6,6,6,2,9]
5
2
=> [27]

# Count before value: 4 beats 9 in the middle window.
[9,4,4,9,7,7]
4
1
=> [18,8,14]

# Fewer distinct values than x: the whole window counts.
[4,4,7,4]
4
3
=> [19]

# The values 1 and 50, at the bounds.
[50,1,50,1,1]
3
1
=> [100,2,2]

# The element leaving the window must stop counting.
[3,3,3,1,1,1]
3
1
=> [9,6,2,3]
