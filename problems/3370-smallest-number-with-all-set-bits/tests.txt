# Smallest Number With All Set Bits.

@example 20 is 10100 in base 2. Counting up from it, the first number with no 0 digit is 11111, which is 31.
20
=> 31

@example 63 is 111111 in base 2, so it is its own answer.
63
=> 63

@example 128 is 10000000. Every number from 128 to 254 has a 0 digit; 255 is 11111111.
128
=> 255

# The smallest n is already all-ones.
1
=> 1

# Powers of two: one more than an all-ones number, so the answer is 2n - 1.
2
=> 3

4
=> 7

8
=> 15

256
=> 511

512
=> 1023

# All-ones numbers come back unchanged.
7
=> 7

15
=> 15

255
=> 255

511
=> 511

# The largest n.
1000
=> 1023
