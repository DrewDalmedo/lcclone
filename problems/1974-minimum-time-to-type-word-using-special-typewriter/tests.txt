# Minimum Time to Type Word Using Special Typewriter.

@example 3 notches from 'a' to 'd', 11 from 'd' to 'o', 8 from 'o' back to 'g', and 3 presses.
"dog"
=> 25

@example Through the seam: 'a' to 'y' and back are 2 notches each, then 10 notches to 'k'; 14 notches and 3 presses.
"yak"
=> 17

@example 'p' is 11 notches from 'a' going backwards past 'z' (15 forwards); the other two 'p's need only presses.
"ppp"
=> 14

# One 'a': no turning, a single press.
"a"
=> 1

# The letter opposite 'a' is 13 notches away either way.
"n"

# 'o' is 14 notches forwards but only 12 backwards, past 'z': the short way
# round must be taken for every distance above 13, not only far ones.
"o"
=> 13

# One notch backwards from 'a' reaches 'z' (not 25 forwards).
"z"
=> 2

# Repeated letters cost one press each and no turning.
"aaaa"
=> 4

# Neighbours across the seam: 'z' to 'a' is 1 notch, 'w' to 'b' is 5.
"za"
=> 4

"wb"
=> 11

# A backwards move: in C, ('c' - 'e') % 26 is -2, not 24.
"ec"
=> 8

"mn"
