# Binary Tree Paths. A case is the tree in level order (null for a missing
# child); the result is one arrow-joined string per leaf, in any order.

@example Each of the two leaves gets a breadcrumb; -9 keeps its minus sign.
[4,-9,7,null,12,null,30]
=> ["4->-9->12","4->7->30"]

@example Two leaves with the same value give the same text, and both count.
[6,2,2]
=> ["6->2","6->2"]

# A lone root at zero: one string, no arrow.
[0]
=> ["0"]

# A lone root at the lower limit, four characters.
[-100]
=> ["-100"]

# A left path: only the bottom node is a leaf.
[3,2,null,1]
=> ["3->2->1"]

# A single-child node in the middle ends no string.
[5,null,6,7]
=> ["5->6->7"]

# One, two and three digits, negative and zero.
[100,-100,10,0,-1]
=> ["100->-100->0","100->-100->-1","100->10"]

# Backtracking: the text to cut back differs in length at each branch.
[1,-100,2,100,3,null,-7]
=> ["1->-100->100","1->-100->3","1->2->-7"]

# Equal routes down different branches.
[7,-7,-7,1,null,1]
=> ["7->-7->1","7->-7->1"]

# A negative root above a negative leaf.
[-5,-5]
=> ["-5->-5"]

# A right path turning left at the bottom.
[9,null,8,null,7,6]
=> ["9->8->7->6"]

# Leaves on different sides at the same depth, one child each above them.
[20,-3,11,8,null,null,-60]
=> ["20->-3->8","20->11->-60"]
