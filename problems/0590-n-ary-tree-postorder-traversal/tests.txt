# N-ary Tree Postorder Traversal. Trees are written level by level, with a
# null closing each node's group of children.

@example 4 comes before its parent 8, and the root comes last.
[5,null,8,2,null,4]
=> [4,8,2,5]

@example 6 and 5 are reported before 4, whose subtree they are.
[1,null,2,3,4,null,null,null,5,null,6]
=> [2,3,6,5,4,1]

@example An empty tree.
[]
=> []

# A lone root.
[7]
=> [7]

# A root with many children keeps their order.
[1,null,5,4,3,2]
=> [5,4,3,2,1]

# A path comes out bottom to top.
[4,null,3,null,2,null,1]
=> [1,2,3,4]

# Two levels of two children: reversing a preorder would swap the siblings.
[1,null,2,3,null,4,5,null,6,7]
=> [4,5,2,6,7,3,1]

# Repeated values.
[3,null,3,3,null,3]
=> [3,3,3,3]

# The value limits.
[10000,null,0,10000,null,0]
=> [0,0,10000,10000]

# The middle child has the subtree.
[1,null,2,3,4,null,null,5,6]
=> [2,5,6,3,4,1]

@gen 1 small
[4,null,5]
=> [5,4]

@gen 2 small
[4,null,2,null,2,0,null,0,0,null,null,4]
=> [4,0,0,2,0,2,4]

@gen 3 small
[2,null,2,1,null,4,null,null,5]
=> [5,4,2,1,2]

@gen 4 small
[3]
=> [3]

@gen 5 small
[1,null,4,3]
=> [4,3,1]

@gen 6 small
[4,null,1,2]
=> [1,2,4]
