# Concatenate Non-Zero Digits and Multiply by Sum I.

@example Dropping the zeros of 3050 gives x = 35. Its digits add up to 8, and 35 * 8 = 280.
3050
=> 280

@example A single digit is its own x and its own digit total: 7 * 7 = 49.
7
=> 49

@example Striking out the only digit of 0 leaves nothing, so x = 0 and the product is 0.
0
=> 0

# The smallest positive n.
