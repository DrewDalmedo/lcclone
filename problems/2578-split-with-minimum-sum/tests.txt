# Split With Minimum Sum.

@example Sorted, the cards are 1, 3, 5, 7. The two smallest take the tens places and the two largest the units, so the rows read 15 and 37, which add up to 52.
7351
=> 52

@example Each 0 card sits at the front of a row, where it costs nothing: 039 + 06, which is 39 + 6 = 45.
30906
=> 45

@example With five cards one row gets three, so the smallest digit, 1, takes the only hundreds place: 148 + 26 = 174.
84126
=> 174

# The smallest num: 1 + 0.
10
=> 1

# Two digits: each pile gets one card.
73
=> 10

# Three digits, two of them zeros: 01 + 0.
100
=> 1

# The only 10-digit input, one 1 and nine zeros: a buffer of 9 digits, or
# of 10 chars with no room for the NUL, overflows.
1000000000
=> 1

# The largest answer: 99999 + 9999.
999999999
=> 109998

# All nine non-zero digits, ascending and descending: 13579 + 2468.
123456789
=> 16047

987654321
=> 16047

# Sorted halves (56 + 78 = 134) and alternating in the original order
# (87 + 56 = 143) both lose to 57 + 68.
8576
=> 125

# Three zeros mixed in: 004 + 015.
400501
=> 19

# Seven different digits, one of them 0: 0258 + 137.
5038271
=> 395

# Nine different digits, one of them 0: 02579 + 1368.
908172635
=> 3947

# Seven equal digits: 5555 + 555.
5555555
=> 6110
