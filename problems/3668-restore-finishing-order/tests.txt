# Restore Finishing Order.

@example Bib 2 finished second, bib 1 fourth and bib 3 last.
[4,2,6,1,5,3]
[1,2,3]
=> [2,1,3]

@example Bib 7 won the race and bib 4 came last.
[7,3,5,1,2,6,4]
[4,7]
=> [7,4]

@example Every runner is a friend, so the answer is the whole sheet.
[2,3,1]
[1,2,3]
=> [2,3,1]

# A single runner.
[1]
[1]
=> [1]

# The sheet in bib order: friends is already the answer.
[1,2,3,4,5]
[2,4,5]
=> [2,4,5]

# The sheet in reverse bib order: friends comes back reversed.
[6,5,4,3,2,1]
[1,3,6]
=> [6,3,1]

# One friend, who finished last.
[2,5,1,4,3]
[3]
=> [3]

# The friends took the first two places.
[8,7,1,2,3,4,5,6]
[7,8]
=> [8,7]

# Eight runners, all of them friends.
[3,8,1,6,2,7,5,4]
[1,2,3,4,5,6,7,8]
=> [3,8,1,6,2,7,5,4]

# Bib numbers are not places: bibs 1, 3 and 2 finished in places 2, 3
# and 4 (counting from 0), and ordering by order[bib - 1] instead gives
# [3,1,2].
[4,5,1,3,2]
[1,2,3]
=> [1,3,2]

# Eight friends out of ten runners, in mixed order.
[9,2,10,4,7,1,8,3,6,5]
[1,2,3,5,6,8,9,10]
=> [9,2,10,1,8,3,6,5]
