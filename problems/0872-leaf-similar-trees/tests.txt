# Leaf-Similar Trees. A case is root1, then root2, each a tree in level order
# with null for a missing child.

@example Both fringes are 7, 12, though the trees differ.
[20,4,9,7,null,null,12]
[1,7,3,null,null,12]
=> true

@example The fringes 4, 3 and 3, 4 hold the same values in another order.
[5,1,null,4,3]
[9,3,2,null,null,4]
=> false

@example The fringe 0, 11 stops where 0, 11, 6 goes on.
[2,0,4,null,null,null,11]
[7,0,3,null,null,11,6]
=> false
