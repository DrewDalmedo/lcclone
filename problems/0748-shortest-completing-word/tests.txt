# Shortest Completing Word.

@example The plate asks for two t's and a k. trek and tusk have one t each; of the other three, kitty is the shortest.
"TK 42 T"
["kitten","trek","takeout","kitty","tusk"]
=> "kitty"

@example ore, rye and her each hold an r and an e in three letters; ore comes first.
"0R 5e"
["oak","ore","rye","her","free"]
=> "ore"

@example P and p together ask for two p's. pea has only one, and pup is the shortest word with two.
"Pp 3"
["pea","apple","pup","puppy"]
=> "pup"

# The smallest plate: one upper-case letter, and a single word.
"Z"
["z"]
=> "z"

# Digits and spaces around the only letter are skipped.
" 5 j  "
["jam","j"]
=> "j"

# r and R add up to two r's, so red is one short.
"rR"
["red","error","rare"]
=> "rare"

# A later, shorter word beats an earlier, longer one; of the two shortest, the first wins.
"ab"
["absorb","bat","cab"]
=> "bat"

# The first shortest word is not at index 0, and a copy of it comes later.
"N0 o"
["moon","on","no","nod","on"]
=> "on"

# Thirty words, each with a w, alternating four and three letters: the first
# three-letter word, owl, wins. A sort by length that isn't stable loses it.
"W 4"

=> "owl"

# A shorter word with one s too few loses to the longer ones.
"ss 2S"
["moss","mosses","stress"]
=> "mosses"

# Seven copies of one letter.
"eEeEeee"
["eeeeee","teepeeseeee","eeeeeee"]
=> "eeeeeee"

# A plate without letters: every word completes it.
