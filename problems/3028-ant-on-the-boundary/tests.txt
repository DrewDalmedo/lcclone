# Ant on the Boundary.

@example After its hops the ant stands at 4, 0, -6 and 0: two landings on the boundary.
[4,-4,-6,6]
=> 2

@example The second hop goes from 5 to -3, over the boundary without stopping; the third lands on it.
[5,-8,3]
=> 1

@example The ant stands at -2, -5 and -4, never on the boundary.
[-2,-3,1]
=> 0

# A single hop never ends on the boundary.
[10]
=> 0

[-1]
=> 0

# The smallest return: out one unit and back.
[1,-1]
=> 1

# All hops go the same way.
[6,2,9,3]
=> 0

# The ant crosses the boundary three times (4, -3, 3, -3) before landing on it.
[4,-7,6,-6,3]
=> 1

# Landings from the left and from the right; the walk goes on after each.
[-3,3,8,-8,-1,1]
=> 3

# Hops of the longest length, both ways: -10, 0, 10, 0.
[-10,10,10,-10]
=> 2

# Only the last hop lands on the boundary, after a long way out.
[9,9,-10,-8]
=> 1
