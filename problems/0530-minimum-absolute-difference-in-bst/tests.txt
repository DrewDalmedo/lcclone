# Minimum Absolute Difference in BST. A case is the tree in level order; the
# result is the smallest gap between the values of two different nodes.

@example In sorted order the values are 10, 17, 20, 30, 35; the nearest two are 17 and 20.
[20,10,35,null,17,30]
=> 3

@example 62 and 64 have the smallest gap, though 62 is a grandchild of 64.
[64,20,90,null,62]
=> 2

@example Two nodes make a single pair.
[9,3]
=> 6

# The smallest tree, child on the left, smallest values.
[1,0]
=> 1

# Two nodes, child on the right, at both bounds: the answer is 10^5.
[0,null,100000]
=> 100000

# Two nodes at the top of the range, child on the left.
[100000,99999]
=> 1

# The closest pair includes 0: a "previous value" of 0 meaning unset skips it.
[10,0,20,null,3]
=> 3

# A small first value and a larger answer: a "previous value" of -1 would give 3.
[2,null,40,30]
=> 10

# Every parent and child are at least 15 apart; the answer is 5.
[50,30,70,10,45,55,90]
=> 5

# Neighbours along a level are no closer than 6; the answer is 3.
[50,20,80,5,47,53,95]
=> 3

# A right path with the closest pair at its deep end.
[1,null,100,null,2000,null,2003]
=> 3

# A left path with the closest pair at its deep end.
[90000,60000,null,30000,null,29999]
=> 1

# The closest pair is the two smallest values.
[500,2,900,1]
=> 1

# The closest pair is the two largest values.
[400,100,800,null,null,799]
=> 1

# A zigzag whose closest pair is a grandparent and grandchild.
[1000,10,null,null,900,20]
=> 10

# Small random trees of distinct values, some spanning the whole range.
@gen 1 small
