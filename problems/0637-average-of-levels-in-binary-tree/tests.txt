# Average of Levels in Binary Tree. A case is the tree in level order, with
# null for a missing child; the result has the mean of each level, top level
# first, and each entry may be off by up to 10^-5.

@example The generations are 6, then 1 and 4, then 3 and 8.
[6,1,4,3,null,null,8]
=> [6.0,2.5,5.5]

@example The third generation is 5 and -6, whose mean is negative and not whole.
[-3,8,null,5,-6,0]
=> [-3.0,8.0,-0.5,0.0]

# A lone root at the top of the int range.
[2147483647]
=> [2147483647.0]

# A lone root at the bottom of the int range.
[-2147483648]
=> [-2147483648.0]

# Two of the largest value overflow a 32-bit sum.
[5,2147483647,2147483647]
=> [5.0,2147483647.0]

# Two of the smallest value overflow it the other way.
[5,-2147483648,-2147483648]
=> [5.0,-2147483648.0]

# The two limits nearly cancel.
[1,2147483647,-2147483648]
=> [1.0,-0.5]

# A negative mean that integer division would cut to -2.
[7,-2,-3]
=> [7.0,-2.5]

# Near 2^31 a float can't tell these apart from a whole number.
[0,2147483647,2147483646]
=> [0.0,2147483646.5]

# A level of three, so the mean doesn't end.
[10,3,-8,7,2,5]
=> [10.0,-2.5,4.666666666666667]

# A path of right children: one entry per node.
[5,null,-4,null,9]
=> [5.0,-4.0,9.0]

# A level of one between levels of two.
[2,3,4,null,8,null,null,6,7]
=> [2.0,3.5,8.0,6.5]

# A level holding the children of one side only.
[9,1,null,2,3]
=> [9.0,1.0,2.5]
