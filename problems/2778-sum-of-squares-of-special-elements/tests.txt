# Sum of Squares of Special Elements.

@example 8 is a multiple of 1, 2, 4 and 8, so the special elements are 2, 6, 7 and 9: 4 + 36 + 49 + 81 = 170.
[2,6,1,7,3,5,4,9]
=> 170

@example 5 is prime, so only the first and the last element are special: 100 + 36 = 136.
[10,3,8,1,6]
=> 136

@example A single element is both the first and the last; its square is counted once.
[7]
=> 49

# Two elements: both are special.
[4,9]
=> 97

# Three elements: the large middle one is not special.
[1,50,1]
=> 2
