# Number of Students Unable to Eat Lunch.

@example The pile holds two 0s and three 1s, just what the line wants, so everyone eats in the end.
[0,1,1,0,1]
[1,1,0,1,0]
=> 0

@example The only student who wants a 0 takes the top sandwich; the next one is a 0 too, and the three left all want a 1.
[1,0,1,1]
[0,0,1,1]
=> 3

@example Nobody wants the 1 on top, so the 0 under it is never reached.
[0,0]
[1,0]
=> 2
