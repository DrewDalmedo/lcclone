# Permutation Difference between Two Strings.

@example m and q move one place each, and z moves two: 1 + 1 + 2.
"mqz"
"zmq"
=> 4

@example Nobody changes place.
"dog"
"dog"
=> 0

@example The order is reversed: w and e move 3 places each, a and k 1 each.
"wake"
"ekaw"
=> 8

# A single runner.
"x"
"x"
=> 0

# Two neighbours swap places.
"ponder"
"opnder"
=> 2

# Two runners 3 places apart swap: 3 each.
"hcfbj"
"hjfbc"
=> 6

# Everyone moves one place forward but the first, who drops to last.
"vwxyz"
"wxyzv"
=> 8

# Three swaps of neighbours.
"lumber"
"ulbmre"
=> 6

# Reversal of an odd length: 6 + 4 + 2 + 0 + 2 + 4 + 6.
"jumping"
"gnipmuj"
=> 24

# All 26 letters, not in alphabetical order, reversed: the largest total.
"qwertyuiopasdfghjklzxcvbnm"
"mnbvcxzlkjhgfdsapoiuytrewq"
=> 338

# All 26 letters, each moving exactly 13 places, which also gives 338.
"abcdefghijklmnopqrstuvwxyz"
"nopqrstuvwxyzabcdefghijklm"
=> 338

# Rotated by 3: 23 letters move 3 places left, 3 letters 23 places right.
"abcdefghijklmnopqrstuvwxyz"
"defghijklmnopqrstuvwxyzabc"
=> 138
