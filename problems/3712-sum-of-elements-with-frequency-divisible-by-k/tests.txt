# Sum of Elements With Frequency Divisible by K.

@example The group of 5s has two entries and survives; the 11s (three entries) and the 7 (one) do not.
[5,11,5,7,11,11]
2
=> 10

@example The group of 9s has four entries, twice k, so all four count; the group of 4s has three.
[9,4,9,9,9,4,4]
2
=> 36

@example The groups have two and three entries, and neither size is a multiple of 4.
[2,7,7,2,7]
4
=> 0

# The smallest input.
[1]
1
=> 1

# The largest value, once.
[100]
2
=> 0

# k = 1: every group survives, so the answer is the sum of the array.
[5,9,5,100,2]
1
=> 121

# k equal to the length: one value survives, two values don't.
[42,42,42,42,42]
5
=> 210

[1,2,1,2]
4
=> 0

# k larger than the length: no group can survive.
[3,3]
100
=> 0

# Groups of size 2k and k both survive.
[2,2,2,2,2,2,7,7,7]
3
=> 33

# 4 occurs four times, twice k; 9 occurs exactly k times.
[4,9,4,4,9,4]
2
=> 34

# Every entry counts: three 10s and three 20s add 90, not 30.
[10,20,10,20,20,10]
3
=> 90

# Unsorted; the only surviving group has the largest value.
[5,3,5,3,3,5,8,8]
2
=> 16
