# Maximum Subarray With Equal Products.

@example [6,1,5,7] has product 210, gcd 1 and lcm 210; taking in the 4 or the 8 as well breaks it.
[4,6,1,5,7,8]
=> 4

@example Two neighbours are always fair (4 and 8: product 32, gcd 4, lcm 8), but no three in a row are.
[4,8,2,4]
=> 2

# A gcd of 1 is not enough: 8 and 2 share a factor, though 3 sits between
# them (product 48, gcd * lcm 24).
[8,3,2]

# 6 is 2 * 3, so it clashes with the 9 (a 3) and with the 4 (a 2): the
# longest fair run is 1, 6, 1, 7. A prime table that gives 6 only one of
# its primes finds 5.
[9,1,6,1,7,4]
=> 4

# 10 is 2 * 5, so it clashes with the 5 and with the 8: the longest fair
# run is 1, 10, 1, 3. Giving 10 only one of its primes finds 5.
[5,1,10,1,3,8]
=> 4

# The same value twice spoils a run, even with a 1 between the two.
[5,1,5]
=> 2

# The longest run is at the start: 7, 1, 3, 1, 1, 10.
[7,1,3,1,1,10,4,6]
=> 6

# The longest run is at the end: 8, 1, 1, 3, 1, 7, 1.
[6,4,10,8,1,1,3,1,7,1]
=> 7

# The whole array.
[1,2,1,3,1,5,1,7,1]

[1,8,9,5,7,1]
