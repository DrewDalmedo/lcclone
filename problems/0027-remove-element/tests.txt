# Remove Element. check: prefix nums with compare: unordered 0, so each
# expected result is the first k elements of nums after the call, in any
# order. They are written here in the order they had in nums.

@example The three 4s go, and 9 and 1 stay, so k = 2. [1,9] would be accepted too.
[4,9,4,1,4]
4
=> [9,1]

@example k = 3. The 0 is kept: only elements equal to val are removed.
[2,8,8,5,8,0]
8
=> [2,5,0]

@example 10 doesn't appear in nums, so nothing is removed and k = 2.
[3,6]
10
=> [3,6]

# An empty array.
[]
0
=> []

# Every element equals val.
[5,5,5]
5
=> []

# A single element, removed and kept.
[0]
0
=> []

[0]
1
=> [0]

# A run of val at the start: the kept elements must move to the front.
[1,1,1,2,3]
1
=> [2,3]

# A run of val at the end.
[6,3,9,9]
9
=> [6,3]

# val in every other place.
[2,7,2,7,2,7]
2
=> [7,7,7]

# Moving the last element into a gap brings in another val, which must go too.
[3,4,5,3,3]
3
=> [4,5]

# Repeated kept values keep their counts.
[10,10,0,10,0,20,0]
0
=> [10,10,10,20]

# The bounds of the values: 0 and 50.
[50,0,50,0]
50
=> [0,0]

# val is above every possible element, so it can't appear.
[50,0,25]
100
=> [50,0,25]
