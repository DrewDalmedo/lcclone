# Substrings of Size Three with Distinct Characters.

@example The triples are kay, aya and yak; aya holds a twice, so 2 of them are good.
"kayak"
=> 2

@example Of the nine triples only mis and sip are good; each of the other seven (iss and ssi twice, sis, ipp, ppi) repeats a letter.
"mississippi"
=> 2

@example dog, ogd, gdo and dog again are all good; dog counts once for each of its two starts.
"dogdog"
=> 4

# Too short to hold a triple: one and two characters.
"a"
=> 0

"ab"
=> 0

# Exactly one triple.
"fox"
=> 1

# Only the two ends are equal; the neighbours differ.
"pop"
=> 0

# The first two equal, the last two equal, and all three equal.
"eel"
=> 0

"see"
=> 0

"ccc"
=> 0

# Only the last triple is good.
"zzzzxy"
=> 1

# Neighbours always differ, but every triple has the same letter at its ends.
"abababab"
=> 0

# The whole alphabet: all 24 triples are good.
"abcdefghijklmnopqrstuvwxyz"
=> 24

# 100 letters cycling through p, q and r: all 98 triples are good.
"pqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrpqrp"
=> 98

# 100 copies of one letter.
"zzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzz"
=> 0
