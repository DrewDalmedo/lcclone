# Minimum Swaps to Move Zeros to End.

@example There are three zeros, so they belong in the last three places. Only the 0 at index 1 is in front of them; swapping it with the 6 gives [3,6,8,0,0,0].
[3,0,8,0,0,6]
=> 1

@example Swap the first 0 with the 4 to get [4,0,0]. The other 0 is already in the back block of two.
[0,0,4]
=> 1

@example Swapping index 0 with index 2 gives [2,6,0,0]: the 6 and the 2 changed order, which is allowed.
[0,6,2,0]
=> 1

# A single zero, and a single non-zero value (the largest one).
[0]
=> 0

[100]
=> 0

# Nothing but zeros, and no zeros at all.
[0,0,0,0]
=> 0

[5,1,5,2]
=> 0

# Five zeros in front of a single non-zero value: one swap settles it,
# though five zeros stand before the last non-zero value.
[0,0,0,0,0,63]
=> 1

# Swaps are not limited to neighbours: two swaps, where moving the zeros a
# step at a time would take four.
[0,0,9,9]
=> 2

# One early zero, a run of non-zero values, then two zeros already at the
# back: returning the number of zeros would be wrong, and keeping the order
# of the non-zero values would shift all five of them.
[0,8,2,6,6,9,0,0]
=> 1

# Zeros and non-zero values taking turns, starting with either, at even and
# odd lengths.
[0,1,0,1,0,1]
=> 2

[0,7,0,7,0]
=> 1

[3,0,3,0,3,0]
=> 1

[100,0,100,0,100]
=> 1
