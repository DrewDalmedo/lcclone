# Last Visited Integers.

@example The first lookup gets 3. After 5 is logged, a streak of four lookups gets 5, 3, 7 and then -1: the log holds only three numbers.
[7,3,-1,5,-1,-1,-1,-1]
=> [3,5,3,7,-1]

@example The first lookup finds the log empty. 4 is logged twice, so the next streak gets 4 twice before it runs out.
[-1,4,4,-1,-1,-1]
=> [-1,4,4,-1]

@example There are no lookups, so there are no answers.
[9,8]
=> []

# The smallest inputs: one number, or one lookup.
[5]
=> []

[-1]
=> [-1]

# A positive entry between streaks starts the count again at t = 1.
[2,-1,-1,6,-1,-1,-1,1,-1]
=> [2,-1,6,2,-1,1]

# A streak exactly as long as the log ends on the oldest number.
[10,20,30,-1,-1,-1]
=> [30,20,10]

# A lookup that answered -1 doesn't end the streak: the third lookup still
# looks three places back.
[4,-1,-1,-1]
=> [4,-1,-1]

# The log keeps every number logged so far, not only those since the last
# streak.
[8,5,-1,9,-1,-1,-1]
=> [5,9,5,8]

# A positive entry ends the streak even when it repeats the newest number
# in the log.
[3,6,-1,6,-1,-1,-1]
=> [6,6,6,3]

# A repeated value takes a place in the log for each occurrence; 100 is the
# largest value.
[100,1,100,-1,-1,-1,-1]
=> [100,1,100,-1]

# Lookups before anything is logged.
[-1,-1,7,-1,-1]
=> [-1,-1,7,-1]
