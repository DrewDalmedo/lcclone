# Maximum Depth of N-ary Tree. Trees are written level by level, with a null
# closing each node's group of children.

@example The longest path is 5 -> 8 -> 4.
[5,null,8,2,null,4]
=> 3

@example The deepest branch is under the root's last child: 1 -> 4 -> 5 -> 6.
[1,null,2,3,4,null,null,null,5,null,6]
=> 4

@example An empty tree has no nodes on any path.
[]
=> 0

# A lone root.
[7]
=> 1

# A root with many children.
[1,null,2,3,4,5,6]
=> 2

# A path, one child each.
[1,null,2,null,3,null,4]
=> 4

# The deepest branch is under a middle child.
[1,null,2,3,4,null,null,5,null,null,6]
=> 4

# The first child is the deep one.
[1,null,2,3,null,4,null,null,5]
=> 4

# Every path has the same length.
[1,null,2,3,null,4,5,null,6,7]
=> 3

# Equal values on every level, and the value limits.
[10000,null,0,0,null,10000]
=> 3

@gen 1 small
[4,null,5]
=> 2

@gen 2 small
[4,null,2,null,2,0,null,0,0,null,null,4]
=> 5

@gen 3 small
[2,null,2,1,null,4,null,null,5]
=> 4

@gen 4 small
[3]
=> 1

@gen 5 small
[1,null,4,3]
=> 2

@gen 6 small
[4,null,1,2]
=> 2

# Full size, 10^4 nodes: a path of 1000 with the rest hung at random, a root
