# Path Sum. A case is the tree in level order (null for a missing child), then
# targetSum; the result says whether some fall from root to leaf scores it.

@example The fall 6, -2, 4 scores 8.
[6,-2,9,null,4,1]
8
=> true

@example 7 + 3 is 10, but 3 isn't a leaf; the two falls score 5 and 12.
[7,3,null,-5,2]
10
=> false

# An empty tree has no falls, even for target 0.
[]
0
=> false

# A lone root equal to the target, at the lower limit.
[-1000]
-1000
=> true

# A lone root that misses the target by one.
[999]
1000
=> false

# The root's value is the target, but the root has a child.
[5,3]
5
=> false

# The first two values reach the target at a one-child node; the path goes on.
[2,null,5,-3]
7
=> false

# The score passes the target and comes back to it.
[10,20,null,-25]
5
=> true

# Zeros below a matching prefix keep the score equal down to the leaf.

7
=> true
