# Diameter of Binary Tree. A case is the tree in level order, with null for
# a missing child; the result is the number of edges on the longest route
# between two nodes.

@example The route 3, 4, 2, 6, 9 uses 4 corridors, and none is longer.
[6,2,9,1,4,null,null,null,null,3,7]
=> 4

@example The route 3, 2, 1, 8, 7, 9, 4 turns at 8 and never reaches the root.
[5,8,null,1,7,2,null,null,9,3,null,null,4]
=> 6

# A lone node has no edges.
[3]
=> 0

# Two nodes, a right child, values at the limits.
[-100,null,100]
=> 1

# A path of left children: the root is one end.
[9,8,null,7,null,6,null,5]
=> 4

# A path of right children.
[9,null,8,null,7]
=> 2

# A zigzag path.
[4,7,null,null,1,6]
=> 3

# A perfect tree: leaf to leaf through the root.
[4,2,6,1,3,5,7]
=> 4

# Through the root with arms of 3 and 2.
[7,4,9,2,null,null,11,1]
=> 5

# A short left side: the best route lies inside the right subtree.
[10,20,30,null,null,40,50,60,null,null,70,80,null,null,90]
=> 6

# The turning point is two levels below a bare path from the root.
[4,8,null,15,null,16,23,42,null,null,5,6,null,null,7]
=> 6

# All values equal.
[0,0,0,null,0,0]
=> 4
