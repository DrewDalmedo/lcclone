# Find Minimum Operations to Make All Elements Divisible by Three.

@example 14 is raised to 15 and 4 is lowered to 3; 30 is already a multiple of 3.
[14,4,30]
=> 2

@example Each 8 is raised to 9 and 26 to 27, one nudge apiece.
[8,26,8]
=> 3

@example The only element is lowered to 0, which is a multiple of 3.
[1]
=> 1

# A single element that is already a multiple of 3.
[3]
=> 0

# The smallest value two above a multiple: raising it once is enough.
[2]
=> 1

# The largest values: 48 stays, 49 goes down to 48, 50 goes up to 51.
[48,49,50]
=> 2

# Every element is already a multiple of 3.
[45,18,33,3,27]
=> 0

# Only elements one above a multiple: each is lowered once (raising would
# take two nudges).
[4,7,10,13,1,49,25]
=> 7

# Only elements two above a multiple: each is raised once (lowering would
# take two nudges).
[2,5,8,50,35,20]
=> 6

# Copies of a value each count.
[11,11,11,12,12]
=> 3

# Both kinds of remainder, with multiples between them.
[16,17,18,19,20,21]
=> 4

# The longest array, with every element needing a nudge.
