# Array Partition.

@example Sorted, the values are -3, 0, 5, 8. Pairing -3 with 0 and 5 with 8 gives -3 + 5 = 2; the two other ways of pairing give -3 + 0 = -3.
[8,-3,5,0]
=> 2

@example Sorted, the values are 1, 2, 3, 9, 9, 10; pairing neighbours in that order gives 1 + 3 + 9.
[10,1,9,2,9,3]
=> 13

@example Every value is negative, and so is the answer: -9 goes with -6, and -4 with -1.
[-4,-9,-1,-6]
=> -13

# The shortest input: a single pair, which gives its smaller value.
[5,-2]
=> -2

# Both bounds.
[-10000,10000]
=> -10000

# All values equal: n times that value.
[-6,-6,-6,-6,-6,-6]
=> -18

# Values on both sides of zero.
[0,-1,1,0]
=> -1

# Pairing neighbours in the given order gives 1 + 2 = 3; sorting first does better.
[1,9,2,8]
=> 9

# Pairing the smallest value with the largest, and so on inwards, gives 1 + 2 + 3 = 6.
[6,1,4,2,5,3]
=> 9

# Three consecutive values that each occur three times: the last copy of each pairs with the first copy of the next.
[6,8,5,7,5,6,7,5,7,6]
=> 30

# Values that occur an odd number of times, with gaps between them.
[20,-50,9999,20,-50,0,20,-50]
=> -60
