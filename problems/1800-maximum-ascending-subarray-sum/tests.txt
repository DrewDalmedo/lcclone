# Maximum Ascending Subarray Sum.

@example The rising slices that can't be made longer are [3,6], [2,4,9] and [1]; [2,4,9] has the largest total.
[3,6,2,4,9,1]
=> 15

@example Equal neighbours don't rise, so each 8 is a rising slice on its own.
[8,8,8]
=> 8

@example [1,2,3,4] is the longest rising slice but totals only 10; the 40 on its own beats it.
[40,1,2,3,4]
=> 40

# A single value.
[7]
=> 7

# Strictly falling: every rising slice is one value, so the largest value wins.
[9,7,5,3]
=> 9

# Equal values at the top bound.
[100,100]
=> 100

# The best slice is the first one.
[21,35,44,1,2,3]
=> 100

# The best slice is in the middle.
[6,1,57,64,2,3]
=> 122

# The best slice is the last one, and only a check after the loop sees it.
[11,26,4,33,47]
=> 84

# The equal 23s split the array: [14,23] and [23,31], not one slice of 91.
[14,23,23,31]
=> 54

# A single drop splits the slice even though big values follow it.
[1,2,3,2,99,100]
=> 201

# The new slice starts with the value that broke the old one: 9 + 46.
[52,9,46]
=> 55

# A long slice of middling values beats one big value.
[99,12,18,25,31,47]
=> 133

# The answer passes 255.
[90,95,99,100]
=> 384
