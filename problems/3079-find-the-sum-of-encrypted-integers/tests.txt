# Find the Sum of Encrypted Integers.

@example 47 becomes 77, 5 stays 5 and 309 becomes 999.
[47,5,309]
=> 1081

@example Zeros are overwritten too: 111 + 1111.
[100,1000]
=> 1222

@example Both copies of 62 count: 66 + 66 + 8.
[62,62,8]
=> 140

# The smallest input.
[1]
=> 1

# The only four-digit number.
[1000]
=> 1111

# Single digits stay as they are.
[3,9,2]
=> 14

# Zeros inside and at the end keep their places: 111 + 111 + 22 + 555.
[101,110,20,500]
=> 799

# The highest digit is in the middle or at the end: 999 + 888 + 888.
[192,128,381]
=> 2775

# The first digit is not the highest: 22 + 44 + 99.
[12,34,19]
=> 165

# Each number is encrypted on its own: 4 + 8, not the encrypted 12.
[4,8]
=> 12

# Numbers whose digits are already all the highest one, or nearly.
[999,990,99]
=> 2097

# One number of each length: 7 + 77 + 777 + 1111.
[7,70,700,1000]
=> 1972

# The largest sum, 50 times 1111, too big for a 16-bit signed integer.
[1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000,1000]
=> 55550
