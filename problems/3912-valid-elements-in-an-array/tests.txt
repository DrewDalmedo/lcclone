# Valid Elements in an Array. The answer lists heights, not indices, in
# index order.

@example 3 is the first post; 4 is taller than 3 and 1 before it; the 2 at index 3 is hidden by 4 from the left and by the equal last post from the right; the last 2 is always seen.
[3,1,4,2,2]
=> [3,4,2]

@example 7 is seen from the left, and 6 from the right because only 1 stands after it; 3 is hidden both ways.
[2,7,3,6,1]
=> [2,7,6,1]

@example The second 8 is hidden from the left by the first 8 and from the right by the last 8, since an equal height is enough; 3 is hidden both ways; only the two ends are seen.
[8,8,3,8]
=> [8,8]

# A single post is listed once.
[42]
=> [42]

# Two posts are both ends, even when equal.
[7,7]
=> [7,7]

[100,1]
=> [100,1]

# Every inner post is lower than both ends.
[50,3,7,2,49]
=> [50,49]

# The tallest height three times: the first copy is seen from the left, the
# last from the right, the middle one from neither.
[4,9,2,9,5,9,1]
=> [4,9,9,1]

# The ends and an inner post all hold the tallest height.
[10,3,10,4,10]
=> [10,10]

# An inner post seen from both ends is listed once.
[3,1,100,2,5]
=> [3,100,5]

# A post tying the tallest before it, but taller than all after it.
[5,2,5,1]
=> [5,5,1]

# The same height seen twice, at the two ends, around a taller post.
[3,1,4,1,3]
=> [3,4,3]

# The smallest and largest heights.
[1,100,1]
=> [1,100,1]

# Strictly falling: every post is seen from the right.
[60,50,40,30,20,10]
