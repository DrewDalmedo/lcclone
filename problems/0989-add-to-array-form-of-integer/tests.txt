# Add to Array-Form of Integer.

@example 358 + 67 = 425.
[3,5,8]
67
=> [4,2,5]

@example 996 + 5 = 1001: the carry runs past the first digit, so the answer gains a digit.
[9,9,6]
5
=> [1,0,0,1]

@example k has more digits than num: 4 + 9870 = 9874.
[4]
9870
=> [9,8,7,4]

# N = 0: the answer is just the digits of k.
[0]
1
=> [1]

[0]
10000
=> [1,0,0,0,0]

# One digit in num and five in the answer: a buffer of num.length + 1 is too small.
[9]
9999
=> [1,0,0,0,8]

# The largest four-digit N plus the largest k.
[9,9,9,9]
10000
=> [1,9,9,9,9]

# k is longer than num, and nothing carries.
[1,2]
10000
=> [1,0,0,1,2]

# Five digits plus 10^4 make six.
[9,0,0,0,0]
10000
=> [1,0,0,0,0,0]

# The carry dies partway up; the digits above it stay as they are.
[7,0,0,4,9,9]
3
=> [7,0,0,5,0,2]

# k changes only a middle digit; zeros on both sides of it.
[5,0,0,0,0,0,0]
10000
=> [5,0,1,0,0,0,0]
