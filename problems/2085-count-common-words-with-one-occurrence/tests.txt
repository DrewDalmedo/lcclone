# Count Common Words With One Occurrence.

@example "green" is once in each list; "blue" is twice in words1, and "red" and "pink" are each in one list only.
["red","blue","green","blue"]
["blue","green","pink"]
=> 1

@example Every word is once in each list, in another order.
["sun","moon","star"]
["star","moon","sun"]
=> 3

@example "ox" is repeated in words1, so it is not paired.
["ox","ox"]
["ox"]
=> 0

# Single words.
["a"]
["a"]
=> 1

["a"]
["b"]
=> 0

# No word in common.
["aa","bb","cc"]
["dd","ee"]
=> 0

# Once in words1 but twice in words2.
["cat","dog"]
["dog","cat","cat"]
=> 1

# Three times in words1 and once in words2: counting pairs of positions
# would give 3 for "hi".
["hi","hi","hi","yo"]
["hi","yo"]
=> 1

# Repeated in both lists.
["x","x","y"]
["x","x","y"]
=> 1

# Twice in one list and absent from the other: two occurrences in all,
# but not one in each list.
["pq","pq"]
["rs"]
=> 0

# Prefixes and near misses are different words.
["ab","abc","abd","b"]
["abc","a","abd","bb"]
=> 2

=> 1
