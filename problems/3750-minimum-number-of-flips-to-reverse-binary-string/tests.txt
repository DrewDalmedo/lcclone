# Minimum Number of Flips to Reverse Binary String. n is written in decimal.

@example 52 is 110100 and its mirror is 001011: not one position agrees, so the answer is the full length, 6.
52
=> 6

@example 27 is 11011, which reads the same from both ends: nothing to change.
27
=> 0

@example 18 is 10010 and its mirror is 01001. The middle bit always matches itself; the other four bits differ.
18
=> 4

# The smallest n: a single bit.
1
=> 0

# Two bits: 10 against 01.
2
=> 2

# Odd lengths: 101 is its own mirror; 110 against 011 differs at both ends.
5
=> 0

6
=> 2

# An even length: 1001 is its own mirror.
9
=> 0

# An even n ends in 0, which faces the leading 1: 1110 against 0111.
14
=> 2

# A power of two: 1000000 against 0000001.
64
=> 2

# 2^29, 30 bits: only the outer pair differs.
536870912
=> 2

# 2^29 - 1: 29 ones.
536870911
=> 0

# The largest n: 111011100110101100101000000000 has 9 differing pairs.
1000000000
=> 18

# 30 bits whose 15 mirror pairs all differ: the largest answer there is.
536903678
=> 30

999991688
=> 30
