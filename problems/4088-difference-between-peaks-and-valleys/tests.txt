# Difference Between Peaks and Valleys.

@example 7 at index 1 is a peak and -4 at index 4 a valley, so 7 - (-4) = 11. Each 3 has an equal neighbour, so neither counts.
[2,7,3,3,-4,1]
=> 11

@example 1 and 2 are valleys and the 6 between them is a peak: 6 - (1 + 2) = 3.
[6,1,6,2,9]
=> 3

@example The list falls to 4 and then climbs, so 4 is the one valley and there is no peak: 0 - 4 = -4.
[9,7,4,6,8,10]
=> -4

# The shortest lists, with a single inner index: a peak, then a valley
# below zero, which adds to the result.
[-6,4,-6]
=> 4

[0,-100,0]
=> 100

# A plateau at the top of a hump, and one at the bottom of a dip.
[1,5,5,1]
=> 0

[30,-7,-7,-7,30]
=> 0

# Strictly falling: the ends are the highest and lowest, but never count.
[100,40,10,-100]
=> 0

# Every value negative: peaks -1 and -2, valley -7.
[-3,-1,-7,-2,-9]
=> 4

# Peaks of 0 add nothing; the valleys between them still count.
[-1,0,-1,0,-1]
=> 1

# A valley right after a peak, and another peak right after it.
[0,3,-2,4,-1]
=> 9

# Every element the same: no peaks and no valleys.
[-100,-100,-100,-100]
=> 0

# Only peaks, kept apart by equal neighbours, all negative: the result is
# negative.
[-10,-4,-10,-10,-6,-10]
=> -10
