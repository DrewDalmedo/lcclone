# Minimum Right Shifts to Sort the Array. -1 means that no number of right
# shifts sorts the array.

@example The smallest value, 2, is at index 2; three right shifts carry it to index 0 and give [2,4,5,7,9].
[7,9,2,4,5]
=> 3

@example These values already increase from left to right, so no shift is needed.
[3,11,25,60]
=> 0

@example Right shifts can only give [5,1,7,3], [3,5,1,7], [7,3,5,1] and [1,7,3,5], and none of them is increasing.
[5,1,7,3]
=> -1

# A single value is already in order.
[42]
=> 0

# Two values: in order, or one shift away.
[3,8]
=> 0

[100,1]
=> 1

# The smallest value is last: one shift.
[2,5,7,9,1]
=> 1

# The smallest value is second: n - 1 shifts, the most possible.
[50,1,2,3,4,5]
=> 5

# Right shifts, not left ones: the smallest value is at index 6 of 8, so
# the answer is 2, while 6 left shifts would also sort it.
[11,12,13,14,15,16,1,2]
=> 2

# Only one drop inside the array (9 to 1), but the last value, 5, is larger
# than the first, 3: no rotation is increasing.
[3,4,9,1,5]
=> -1

# A rotation of 1 to 8 with a pair swapped next to the drop: two drops.
[6,7,1,8,2,3,4,5]
=> -1

# Read from the smallest value round the ends, 1, 2, 4, 8 increase and only
# the very last step, 8 to 6, goes down.
[8,6,1,2,4]
=> -1

# Decreasing values.
[9,7,4,2]
=> -1
