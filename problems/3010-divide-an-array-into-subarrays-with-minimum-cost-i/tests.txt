# Divide an Array Into Subarrays With Minimum Cost I.

@example Cut into [6,9], [2,8] and [5]: 6 + 2 + 5 = 13.
[6,9,2,8,5]
=> 13

@example With three elements, each one is a piece of its own.
[8,2,6]
=> 16

@example 25 starts the first piece, so it is always paid for. The best cut gives [25], [6] and [3,40,7]: 25 + 6 + 3 = 34.
[25,6,3,40,7]
=> 34

# The smallest answer there can be.
[1,1,1]
=> 3

# The largest answer, 150: more than a signed char holds.
[50,50,50]
=> 150

# The first element is the smallest; it is paid for once, not twice.
[1,5,3,8]
=> 9

# A large first element: the three smallest elements are the 1s, but the
# first piece starts with 50.
[50,1,1,1]
=> 52

# The two smallest after the first are equal and next to each other.
[9,2,2,7]
=> 13

# A single 1 can start only one piece.
[50,1,50]
=> 101

# Only one 1 after the first element: one piece begins with it, and the
# other has to begin with a 9.
[4,1,9,9]
=> 14

# The smallest elements are at position 1 and at the end.
[8,1,6,7,2]
=> 11

# A falling tail: the two smallest are the last two, each one smaller than
# everything before it.
[10,9,8,7,6,5]
=> 21

# Fifty elements: 50 everywhere but at the second and last positions.
[50,1,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,1]
=> 52

# Fifty elements, all 50.
[50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50,50]
