# Sum of Left Leaves. A case is the tree in level order (null for a missing
# child); the result is the sum of the childless left children.

@example The left leaves are 6 and 3; 40 is a right child and -5 has a child.
[12,-5,8,6,null,3,40]
=> 9

@example The only left leaf hangs below a right child.
[2,null,-4,9]
=> 9

# A lone root has no parent, so it doesn't count.
[-1000]
=> 0

# The root's only child is a right leaf.
[3,null,4]
=> 0

# A right leaf below a left child: neither node counts.
[1,2,null,null,3]
=> 0

# A left child with only a right child isn't a leaf; the left leaf below is.
[5,6,null,null,7,8]
=> 8

# A left leaf deep under right children; the left child above it has a child.
[1,null,2,3,4,5,null,null,6]
=> 5

# A negative answer.
[0,-7,2,-3,null,-8]
=> -11
