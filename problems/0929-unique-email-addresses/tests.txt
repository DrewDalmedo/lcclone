# Unique Email Addresses.

@example The first two both reach the mailbox kimlee@mail.com, and the third reaches leekim@mail.com.
["kim.lee+news@mail.com","kimlee@mail.com","lee.kim@mail.com"]
=> 2

@example The first two share n@v.com; n@w.com has another domain and m@v.com another user.
["n+1@v.com","n+2@v.com","n.+3@w.com","m@v.com"]
=> 3

@example Cutting at the first + leaves q every time.
["q+r.s@zz.com","q+@zz.com","q@zz.com"]
=> 1

# A single address.
["a@b.com"]
=> 1

# The same address three times.
["mo@x.com","mo@x.com","mo@x.com"]
=> 1

# Dots in the domain stay: ab.c.com and abc.com are two domains.
["x@ab.c.com","x@abc.com","x.@abc.com"]
=> 2

# The @ is part of the mailbox: without it both would read abc.com.
["ab@c.com","a@bc.com"]
=> 2

# The same user at two domains, and another user at the first domain.
["pat@one.com","pat@two.com","p.a.t@one.com","pam@one.com"]
=> 3

# Several + signs: the cut is at the first, and dots after it don't matter.
["ann+a+b@q.com","ann+.x.@q.com","a.n.n@q.com"]
=> 1

# Dots first, last, before the +, and in runs.
[".jo@k.com","jo.@k.com","j..o.+z@k.com","jo@k.com","j.o.e@k.com"]
=> 2

# A + in the domain stays where it is.
["ed@mail+x.com","ed@mail+y.com","e.d@mail+x.com"]
=> 2

["ed+1@m+x.com","ed+2@m+x.com"]
=> 1

# User parts that become empty.

=> 2

# Users made of the same letters are still different users.
["listen@x.com","silent@x.com","enlist@x.com"]
