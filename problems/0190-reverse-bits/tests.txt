# Reverse Bits. Values are unsigned 32-bit integers in decimal.

@example 6 is 29 zero bits followed by 110. Reversed, that is 011 followed by 29 zeros, which is 2^30 + 2^29.
6
=> 1610612736

@example Only the lowest bit is set, so only the highest is set afterwards: 2^31.
1
=> 2147483648

@example The low 16 bits are set; reversed, the high 16 bits are.
65535
=> 4294901760

# Nothing to move.
0
=> 0

4294967295
=> 4294967295
