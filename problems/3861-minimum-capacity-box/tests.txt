# Minimum Capacity Box. The result is a 0-based box index, or -1.

@example The item fits in boxes 0, 2, 3 and 4; the smallest of these hold 7, and box 2 comes before box 4.
[9,4,7,12,7]
6
=> 2

@example Box 2 is exactly as big as the item, which counts as a fit, and is smaller than box 1.
[3,8,5]
5
=> 2

@example Every box is smaller than the item.
[2,3,1]
4
=> -1

# One box, which fits exactly.
[5]
5
=> 0

# One box, too small.
[3]

=> -1

# The largest possible item fits nowhere.
[99,98,1,50]
100
=> -1

# Only the boxes of capacity 100 take the largest item; the first of them wins.
[99,100,42,100]
100
=> 1

# An item of size 1 fits everywhere: the smallest box overall, the first of a tie.
[3,1,2,1]

=> 1
