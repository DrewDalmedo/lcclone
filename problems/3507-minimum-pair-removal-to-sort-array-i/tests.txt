# Minimum Pair Removal to Sort Array I.

@example The pair sums are 4 and 3, so 1 and 2 are fused into 3, and [3,3] is non-decreasing.
[3,1,2]
=> 1

@example Both pairs sum to 4, so the left pair is fused: [4,-3] still drops, and one more fusion leaves [1].
[-3,7,-3]
=> 2

@example The array is already non-decreasing, so nothing is fused.
