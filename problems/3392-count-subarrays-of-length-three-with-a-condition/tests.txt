# Count Subarrays of Length Three With a Condition.

@example Only 10 is a pivot: its neighbours 3 and 2 add up to 5, half of 10.
[3,10,2,-6,0]
=> 1

@example 9 is odd, so its half is 4.5, and its neighbours add up to 4; -1 is odd as well.
[5,9,-1,4]
=> 0

@example Both -2s are pivots (1 + -2 = -1 is half of -2 each time), though their subarrays share two elements.
[1,-2,-2,1]
=> 2

# The fewest elements, with a pivot.
[4,12,2]
=> 1

# The neighbours add up to twice the middle (2 = 2 * 1): the rule turned around, which doesn't count.
[6,1,-4]
=> 0

# The first two add up to half of the last (1 + 2 = 6 / 2), which doesn't count either.
[1,2,6]
=> 0

# All zeros: every middle position is a pivot, 98 at the largest length.

# Odd middles 7 and 9 whose halves, rounded down, equal their neighbours' sums 3 and 4.
[2,7,1,9,3]
=> 0

# Odd negative middles: -7 / 2 rounded toward zero is -3 = -1 + -2, and -15 / 2 rounded down is -8 = -2 + -6.
[-1,-7,-2,-15,-6]
=> 0

# Twice the neighbours' sum is -10 around 10 and 8 around -8: the right size but the wrong sign, so neither counts; -6 between -8 and 5 does.
[3,10,-8,-6,5]
=> 1

# A negative pivot with neighbours of mixed signs, and 0 between 7 and -7.
[5,-4,-7,0,7]
=> 2

# The only pivot is in the last subarray.
[1,1,1,1,3,8,1]
=> 1

# The only pivot is in the first subarray, at the lowest value.
[-50,-100,0,1,1]
=> 1

# The extreme values 100 and -100 as pivots.
[25,100,25,-100,-75]
=> 2

# The same three values at two places count twice.
[6,20,4,6,20,4]
=> 2
