# Distribute Elements Into Two Arrays I. The answer is the top row, then the bottom row.

@example 6 starts the top row and 9 the bottom one. 4 goes below (6 < 9), 7 and 2 go on top (6 > 4, then 7 > 4), and 8 goes below (2 < 4).
[6,9,4,7,2,8]
=> [6,7,2,9,4,8]

@example 10 > 3 sends 20 to the top row, then 20 > 3 sends 30 there too; the bottom row keeps only 3.
[10,3,20,30]
=> [10,20,30,3]

@example 12 < 15 sends 40 to the bottom row, so the answer is nums as it was.
[12,15,40]
=> [12,15,40]

# The smallest input, with the one placement going to the top row.
[3,1,2]
=> [3,2,1]

# A run in the top row, then a switch: the bottom row's last number is
# older than the number before.
[50,10,60,70,5,80]
=> [50,60,70,5,10,80]

# A long run in the bottom row, one number on top, then another run below.
[30,60,45,50,20,10,70,80,15,5]
=> [30,10,60,45,50,20,70,80,15,5]

# Falling numbers: the rows take turns.
[40,90,30,25,20,15,10,5]
=> [40,25,15,5,90,30,20,10]

# Only the last number goes to the top row.
[20,30,40,10,5]
=> [20,5,30,40,10]

# Everything goes to the bottom row, so the answer is nums itself.
[7,8,9,100,2]
=> [7,8,9,100,2]

# The extreme values.
[100,1,50]
=> [100,50,1]

# 50 numbers, 49 of them in the top row: the bottom row keeps only 1.
