# Kth Distinct String in an Array. When there is no answer the expected
# result is the empty string "".

@example "red" and "blue" occur twice each; the one-offs in order are "green", "pink" and "gold".
["red","blue","red","green","pink","blue","gold"]

@example Only "moon" and "star" are one-offs, so there is no third.
["sun","moon","sun","star"]

=> ""

@example "kiwi" occurs three times, so the first one-off is "fig".

# All different, k = arr.length: the last entry, though it comes first
