# Construct Uniform Parity Array I. Every input has the answer true; the
# cases are there to catch solutions that wrongly return false.

@example Copy 3 and 5, and replace 8 by 8 - 3 = 5: the list [3,5,5] is all odd.
[3,8,5]
=> true

@example All three values are already even, so copying them is enough.
[6,2,10]
=> true

@example 7 is the only odd value. Subtract it from every even one: [-3,7,5,13] is all odd, with 7 used three times.
[4,7,12,20]
=> true

# A single value has no other position to subtract; copying it works,
# odd or even.
[7]
=> true

[100]
=> true

# Two values of different parity, in both orders.
[1,2]
=> true

[2,1]
=> true

# The only odd value is the largest, so every difference with it is
# negative and odd.
[10,40,99]
=> true

[100,99]
=> true

# Exactly one even value among odds.
[1,3,5,8]
=> true

# All odd, and all even.
[1,99,33]
=> true
