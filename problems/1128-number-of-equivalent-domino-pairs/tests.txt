# Number of Equivalent Domino Pairs.

@example [6,2] and the two [2,6] tiles are all equivalent, which gives 3 pairs, and the two [5,5] tiles give one more; [4,3] has no partner.
[[6,2],[5,5],[2,6],[4,3],[2,6],[5,5]]
=> 4

@example [1,9] pairs with [9,1] and [2,8] with [8,2]; [3,7] has the same sum as they do but different numbers.
[[1,9],[2,8],[9,1],[8,2],[3,7]]
=> 2

@example No two tiles carry the same two numbers.
[[8,8],[2,4],[4,8]]
=> 0

# A single tile.
[[1,1]]
=> 0

# Two tiles, one turned round.
[[7,3],[3,7]]
=> 1

# Four tiles with the same equal halves: every two of them form a pair.
[[4,4],[4,4],[4,4],[4,4]]
=> 6

# Equal halves next to turned tiles: [2,2] twice, [2,3] twice (once
# turned) and [3,3] three times.
[[2,2],[2,3],[3,2],[3,3],[2,2],[3,3],[3,3]]
=> 5

# All four tiles have the product 6, but only two pairs are equivalent.
[[1,6],[2,3],[6,1],[3,2]]
=> 2

# All four tiles have the xor 5, but only [2,7] and [7,2] are equivalent.
[[1,4],[2,7],[6,3],[7,2]]
=> 1

# The number 9.
[[9,8],[8,9],[9,9],[9,9],[1,9]]
=> 2

# Equivalent tiles only at the two ends of the list.
[[5,9],[1,2],[3,4],[6,7],[9,5]]
=> 1
