# Number of Bit Changes to Make Two Integers Equal. Inputs are written in
# decimal; -1 means k can't be reached.

@example 29 = 16 + 8 + 4 + 1 and 9 = 8 + 1: take away 16 and 4.

9
=> 2

@example 18 = 16 + 2, but 2 is not a part of 28 = 16 + 8 + 4, and no move adds it, though 28 has more parts.

=> -1

@example 8 is not a part of 7 = 4 + 2 + 1; moves only make n smaller.

=> -1
