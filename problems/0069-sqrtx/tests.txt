# Sqrt(x).

@example 7 * 7 = 49 is at most 50, but 8 * 8 = 64 is more.
50
=> 7

@example 144 is a perfect square: 12 * 12.
144
=> 12

@example 143 is one less than 12 * 12, so the answer drops to 11.
143
=> 11

# Zero and one are their own roots.
0
=> 0

1
=> 1

# The answer stays 1 until x reaches 4.
2
=> 1

3
=> 1

# Just below and at a small perfect square.
24
=> 4

25
=> 5

# One below a million.
999999
=> 999

# At and just below 2^30 = 32768 * 32768.

=> 32768

=> 32767

=> 46339
