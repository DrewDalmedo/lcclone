# Count Integers Appearing in a Single Block.

@example The 4s fill indices 0-1 and the 2s fill indices 3-5, each a single block. The two 7s, at indices 2 and 6, have the 2s between them.
[4,4,7,2,2,2,7]
=> 2

@example Each value has a copy of the other value between its two copies.
[9,3,9,3]
=> 0

@example 1 occurs once, which is a block of its own; the last 8 is cut off from the first three by the 1.
