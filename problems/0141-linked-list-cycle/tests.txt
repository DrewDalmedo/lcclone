# Linked List Cycle. A case is the list from head to tail, then pos: the
# index of the node the last node links back to, or -1 for none.

@example The last node, 11, links back to index 2, the second 6.
[6,-1,6,4,11]
2
=> true

@example The same values with no link back: a repeated value is not a cycle.
[6,-1,6,4,11]
-1
=> false

@example One node whose next is itself.
[9]
0
=> true

# The empty list.
[]
-1
=> false

# One node, no cycle.
[9]
-1
=> false

# Two equal values, no cycle.
[2,2]
-1
=> false

# The last node links to itself.
[2,2]
1
=> true

# The loop covers the whole list.
[1,3,5,7,9]
0
=> true

# Only the last node is in the loop.
[1,3,5,7,9]
4
=> true

# The value limits.
[100000,-100000]
1
=> true

# All values equal, no cycle.
[4,4,4,4,4,4]
-1
=> false

# All values equal, a loop in the second half.
[4,4,4,4,4,4]
3
=> true

@gen 1 small
