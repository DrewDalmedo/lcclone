# Count Square Sum Triples.

@example (3, 4, 5), (6, 8, 10) and (5, 12, 13), each with its first two numbers in either order.
13
=> 6

@example No triple fits: the smallest possible c is 5.
4
=> 0

@example Eight right triangles fit, two of them with c = 25: 7, 24, 25 and 15, 20, 25.
25
=> 16

# The smallest n.
1
=> 0

# One below 25: the two triangles with c = 25 drop out.
24
=> 12

# 65 is the longest side of four triangles (16, 63), (25, 60), (33, 56)
# and (39, 52), so going from 64 to 65 adds 8 triples.
64
=> 54

65

# Scaled triangles count too: (60, 80, 100), (28, 96, 100).
100

# 125 is the longest side of three triangles.
125
=> 142

200
=> 254

# Near the top: c = 247 adds one triangle (95, 228), while no triangle

246

# n = 250, the most allowed. c = 250 adds three triangles. Legs up to 250
# with c above 250 must not count: they would make 392.
250
