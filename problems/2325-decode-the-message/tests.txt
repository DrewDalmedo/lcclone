# Decode the Message.

@example The list is l, m, ..., z, a, ..., k: l stands for a, m for b, and so on, so each letter moves 11 places back in the alphabet, going round from a to z.
"lmnop qrstuvwxyz abcdefghijk"
"nwplc dvj"
=> "clear sky"

@example The list begins z, o, e, b, r, a, y, k (the second o, the second z and the a of "yak" are passed over), then c, d, f, ..., x. So o stands for b, c for i, y for g, and so on.
"zoo zebra yak cdfghijlmnpqstuvwx"
"ocy ezqp izl"
=> "big cats nap"

@example The list is the alphabet backwards, so each letter becomes its mirror image; the spaces stay where they are.
"zyxwvutsrqponmlkjihgfedcba"
" abc  xyz"
=> " zyx  cba"

# The plain alphabet as key changes nothing; spaces at both ends are kept.
"abcdefghijklmnopqrstuvwxyz"
"  quiet  "
=> "  quiet  "

# A message of spaces only.
"bcdefghijklmnopqrstuvwxyza"
"   "
=> "   "

# One letter. The list is the alphabet moved one place, so a, its last
# letter, stands for z (looking it up the other way round gives b).
"bcdefghijklmnopqrstuvwxyza"
"a"
=> "z"

# Spaces at the start of key and doubled inside it take no place in the
# list; runs of spaces in the message, and spaces at both ends, are kept.
"  mn  bv cxz lkjhgfdsa poiuytrewq"
" rkvc   sacd "
=> " wide   open "

# Letters repeat long before the alphabet is complete; only their first
# appearance counts, and a repeat doesn't use up a plain letter.
"need a deed fade bcghijklmopqrstuvwxyz"
"deaf need fade"
=> "cbde abbc edcb"

# A key of exactly 26 letters, and every letter in the message once.
"qazwsxedcrfvtgbyhnujmikolp"
"abcdefghijklmnopqrstuvwxyz"
=> "boihgknqvtwyurxzajemsldfpc"
