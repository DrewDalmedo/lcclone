# Number of Days Between Two Dates.

@example The later date comes first. February 2033 has 28 days, so the steps go to the 27th, the 28th and 1 March.
"2033-03-01"
"2033-02-26"
=> 3

@example 7 days to reach 1 January 2000, then 7 more to the 8th.
"1999-12-25"
"2000-01-08"
=> 14

@example The same date twice.
"2088-07-04"
"2088-07-04"
=> 0

# Neighbouring days across the end of a year.
"2045-12-31"
"2046-01-01"
=> 1

# The ends of a 30-day month and of January.
"2061-04-30"
"2061-05-01"
=> 1

"2061-01-31"
"2061-03-01"
=> 29

# 2000 is a leap year: 28 February to 1 March is two steps.
"2000-02-28"
"2000-03-01"
=> 2

# 2100 is not a leap year: one step, here with the later date first.
"2100-03-01"
"2100-02-28"
=> 1

# January to March of the leap year 1972 includes 29 February.
"1972-01-15"
"1972-03-15"
=> 60

# February of the leap year 2096, and of 2097, later date first.
"2096-02-01"
"2096-03-01"
=> 29

"2097-03-01"
"2097-02-01"
=> 28

# Months and days 08 and 09, which an octal-minded parser reads as 0.
"2008-08-09"
"2009-09-08"
=> 395

# Within the first year allowed.
"1971-01-01"
"1971-12-31"
=> 364

# 32768 days: one more than a signed 16-bit count holds.
"1971-01-01"
"2060-09-18"
=> 32768

# The whole range, later date first: the largest answer possible.
"2100-12-31"
"1971-01-01"
=> 47481
