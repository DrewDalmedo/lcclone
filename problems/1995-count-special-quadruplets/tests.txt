# Count Special Quadruplets.

@example 2 + 5 + 1 = 8 is the only special pick; no three values before the 4 add up to 4.
[2,5,1,8,4]
=> 1

@example The three 2s add up to 6, and each of the two 6s lies to their right.
[2,2,2,6,6]
=> 2

@example 4 + 3 + 2 = 9, but the 9 comes first, and the sum must be at the last index.
[9,4,3,2]
=> 0

# Four values: the sum last, then the sum first.
[2,1,1,4]
=> 1

[4,2,1,1]
=> 0

# All values equal: x + x + x is never x.
[7,7,7,7,7,7,7]
=> 0

# Largest values: three addends reach 100; 100 + 100 + 100 is too much.
[40,25,35,100]
=> 1

[100,100,100,100]
=> 0

# The difference 100 - 1 = 99 meets the sum 49 + 50.
[49,50,1,100]
=> 1

# The first 6 has nothing before it; the last one is 2 + 1 + 3.
[6,2,1,3,6]
=> 1

# The same values in another order: the 9 no longer follows 2, 3 and 4.
[2,3,4,9,5]
=> 1

[2,3,9,4,5]
=> 0

# The 4 is a sum (1 + 2 + 1) and then an addend of 7 with one of the two
# 1s and one of the two 2s: 1 + 2 * 2 = 5.
[1,2,1,4,2,7]
=> 5

# Repeated values: two picks reach the 4 and two reach the 5.
[1,2,1,2,4,5]
=> 4

# 38 ones, then 12 threes: C(38,3) * 12 = 8436 * 12 = 101232, more than a
