# Shortest Distance to Target String in a Circular Array.

@example The only "lime" is on seat 5: counterclockwise from seat 1 it takes 2 moves (to seat 0, then seat 5), clockwise it takes 4.
["fig","plum","kiwi","pear","plum","lime"]
"lime"
1
=> 2

@example The "elm" on seat 3 is one move away; the one on seat 1 comes first in the list but is two moves away.
["oak","elm","ash","elm","yew"]
"elm"
4
=> 1

@example No card reads "ta": "tab" only begins with it.
["tab","bat","at"]
"ta"
2
=> -1

# A single seat whose card reads target.
["z"]
"z"
0
=> 0

# A single seat with another word.
["z"]
"zz"
0
=> -1

# The starting seat reads target, and so do others.
["go","on","go","go"]
"go"
2
=> 0

# Start on seat 0; the only copy is on the last seat, one move
# counterclockwise across the seam (seven moves the other way).
["a","b","c","d","e","f","g","h"]
"h"
0
=> 1

# Start on the last seat; the only copy is on seat 0, one move clockwise.
["sun","mon","tue","wed","thu","fri","sat"]
"sun"
6
=> 1

# Clockwise without crossing the seam: two moves, against eight.
["m","n","o","p","q","r","s","t","u","v"]
"p"
1
=> 2

# Copies on seats 0 and 3, start on seat 7 of 9: seat 0 is two moves
# clockwise across the seam, seat 3 four moves counterclockwise.
["ab","ba","aa","ab","bb","ba","aa","bb","ba"]
"ab"
7
=> 2

# The only copy is exactly opposite: both ways take n / 2 moves.
["cup","mug","jar","pot","pan","tin"]
"pan"
1
=> 3

# Near misses only: a prefix of target, target plus a letter, one letter
# changed, and two anagrams.

=> -1
