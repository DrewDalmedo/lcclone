# Maximum Difference Between Adjacent Elements in a Circular Array.

@example The stretches change height by 7, 10, 6 and 3 (the last one from 0 back to 3).
[3,-4,6,0]
=> 10

@example The largest change is on the stretch from 30 back to -20 that closes the loop.
[-20,-15,-12,-18,30]
=> 50

@example Both stretches join the same two checkpoints, 7 apart.
[6,-1]
=> 7

# Two checkpoints at the same height.
[0,0]
=> 0

# The largest possible change.
[100,-100]
=> 200

# -100 and 100 are neighbours only across the wrap.
[-100,0,50,99,100]
=> 200

# All heights equal, and not zero.
[37,37,37,37]
=> 0

# Heights much larger than the changes between them.
[99,98,97]
=> 2

# Low heights: a 0 read past the end of the array would give 100.
[-100,-99,-100]
=> 1

# The largest change is a descent (50 down to -40).
[5,50,-40,-30]
=> 90

# The wrap is the largest change, once a rise and once a drop from the
# last checkpoint to the first.
[-60,-50,-40,40]
=> 100

[70,65,58,-35]
=> 105

# The highest and lowest checkpoints are far apart on the loop.
[100,60,20,-20,-60,-100,-60,-20,20,60]
=> 40

# The largest change is the first stretch.
[-3,80,79,78,77]
=> 83

# The largest change is the last stretch before the wrap (-52 up to 39).
[41,37,45,30,-52,39]
=> 91
