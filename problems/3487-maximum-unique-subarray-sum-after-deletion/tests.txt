# Maximum Unique Subarray Sum After Deletion.

@example Erase -3, -1 and one of the 4s; the survivors 4, 7, 2 form a block with no repeats, scoring 13.
[4,-3,4,7,-1,2]
=> 13

@example Every entry is negative, so the best block is a single -2: it can't be empty.
[-6,-2,-9,-2]
=> -2

@example A block can hold only one 3, and adding the -1 would lower the score.
[3,-1,3,3]
=> 3

# A single entry, whatever its sign.
[100]
=> 100

[-100]
=> -100

[0]
=> 0

# All entries at the lower bound: a best score that starts at 0 is wrong.
[-100,-100,-100]
=> -100

# Zeros among negatives: the best block is a lone 0.
[-4,0,-7,0]
=> 0

# All negative, the largest entry last.
[-9,-5,-1]
=> -1

# Zeros next to a positive add nothing.
[0,7,0]
=> 7

# Repeats and negatives sit between the positives, so without erasing no
# block could take 6, 9 and 1 together.
[6,-50,6,9,-2,1,9]
=> 16

# Erasing the -1 beats the best run of the whole array, 2 - 1 + 3 = 4.
[2,-1,3]
=> 5

# Both bounds, with -100 needing a table slot below 0.
[-100,1,-100,100]
=> 101

# Repeated large values: the score passes what a byte holds.
[100,100,99,-100,98,99]
=> 297
