# Second Minimum Node In a Binary Tree. A case is the tree in level order; the
# result is the smallest value above the root's, or -1 if there is none.

@example The scores are 3, 5, 10 and 14; the next one above the winning 3 is 5.
[3,3,10,3,5,10,14]
=> 5

@example Every node holds 9, so there is no second score.
[9,9,9,9,9]
=> -1

@example Both of the root's children equal it: the second score is further down.
[4,4,4,4,8]
=> 8

# A single node has no second value.
[5]
=> -1

# A single node at the top of the range.
[2147483647]
=> -1

# Every value is 2^31 - 1: still no second value.
[2147483647,2147483647,2147483647,2147483647,2147483647]
=> -1

# The answer is 2^31 - 1, which a sentinel of INT_MAX can't tell from none.
[1,1,2147483647,1,1]
=> 2147483647

# The two largest values possible: val + 1 would overflow.
[2147483646,2147483646,2147483647,2147483646,2147483646]
=> 2147483647

# Copies of the minimum don't count as the second value.
[2,2,2,2,3]
=> 3

# The root's larger child, 7, isn't the answer: 3 is under its equal child.
[1,1,7,1,3]
=> 3

# Candidates in two branches, and the first one met (9) isn't the smallest.
[1,1,1,1,9,1,4]
=> 4

# A spine to the left all equal to the root, the answer at the very bottom.
[2,2,2,2,2,null,null,2,6]
=> 6

# A spine to the right: the deeper 5 beats the 7 above it.
[2,2,2,null,null,7,2,null,null,2,5]
=> 5

# The larger child is the answer, and nothing under it is smaller.
[3,8,3,8,9]
=> 8

# Values past 16 bits.
[70000,70000,70001,70000,70000]
=> 70001
