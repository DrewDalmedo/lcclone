# Find the Middle Index in Array.

@example In front of index 3: 5 - 1 + 4 = 8. Behind it: 2 + 6 = 8. Indices 0, 1 and 2 have 0 and 21, 5 and 22, 4 and 18.
[5,-1,4,10,2,6]
=> 3

@example Indices 2 and 3 both have 6 on each side; the answer is the smaller one.
[1,5,0,0,6]
=> 2

@example The two sums are 0 and -1 at index 0, 9 and -3 at index 1, and 11 and 0 at index 2: never equal.
[9,2,-3]
=> -1

# One element: both sums are empty.
[-7]
=> 0

# Index 0: the elements behind it add up to 0.
[9,4,-6,2]
=> 0

# Only the last index: the elements in front of it add up to 0.
[3,-5,2,11]
=> 3

# Indices 1 and 4 both qualify (10 = 10, then 6 = 6); scanning from the
# right, or keeping the last hit, gives 4.
[10,-6,3,-1,2,6]
=> 1

# nums[i] belongs to neither side. Counting it in front would accept
# index 0 (5 = 2 + 3); counting it behind would accept index 1 (5 = 2 + 3).
[5,2,3]
=> -1

# Halving: at index 1 the total less nums[1] is 11, and 11 / 2 is 5 in C,
# which equals before(1), but after(1) is 6. The same trap catches example
# 3 with a negative: at index 0, -1 / 2 is 0.
[5,6,6]
=> -1

# before rises to 11, past half the total (8), then falls back to 2 at
# index 3: stopping once it passes half the total misses the answer.
[6,5,-9,4,2]
=> 3

# Two elements: index 0 qualifies when the second is 0, index 1 when the
# first is 0, and neither otherwise.
[0,0]
=> 0

[0,-8]
=> 1

[-1000,1000]
=> -1
