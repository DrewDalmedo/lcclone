# Count Pairs Of Similar Strings.

@example The first four words all use exactly l, o and p, which makes 6 pairs; "pole" also uses e.
["loop","pool","polo","lop","pole"]
=> 6

@example "mm" and "m" both use only m, and "xy" and "yx" both use exactly x and y.
["mm","xy","m","yx"]
=> 2

@example "ab" and "bc" each use only part of the letters of "abc", and differ from each other.
["ab","abc","bc"]
=> 0

# A single word has no partner.
["q"]
=> 0

# Two equal words.
["hello","hello"]
=> 1

# The same letters in different amounts: all 6 pairs are similar.
["ttu","tuu","ut","tttu"]
=> 6

# An alphabet strictly inside another is not similar to it, either way
# round; only the two copies of "abc" pair up.
["abc","abcd","abc"]
=> 1

# Different alphabets whose letter codes add up to the same total (ad, bc)
# or xor to the same value (abcd, ae).
["ad","bc","abcd","ae"]
=> 0

# Two groups of three, interleaved, and a word alone: 3 + 3 pairs.
["ab","c","ba","cc","aab","ccc","b"]
=> 6

# The longest word, 100 copies of one letter, with short words of it.
["kkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkkk","k","kk"]
=> 3

# All 26 letters in different orders and amounts; the last word lacks z.
["abcdefghijklmnopqrstuvwxyz","zyxwvutsrqponmlkjihgfedcbammqq","abcdefghijklmnopqrstuvwxyzabcdefghijklmnopqrstuvwxyzabcdefghijklmnopqrstuvwxyzabcdefghijklmnopqrstuv","abcdefghijklmnopqrstuvwxy"]

# The only pair is the first word with the last.
["xyz","a","b","c","zyx"]
=> 1
