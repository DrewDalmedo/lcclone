# Unique Morse Code Words.

@example ye and tan make the same signal (-.--. for both); sun and dot make two others.
["ye","sun","tan","dot"]
=> 3

@example The two copies of go make one signal; og makes another (-----. against --.---).
["go","go","og"]
=> 2

@example tt and m both make --; t makes -, which is shorter and so different.
["t","tt","m"]
=> 2

# A single word.
["zebra"]
=> 1

# One word, four times.

=> 1

# Each signal is the start of the next one, but no two are equal.
["e","i","s","h"]
=> 4

# an and p both make .--., na and x both make -..-: equal lengths, equal numbers of dots and dashes.
["an","na","p","x"]
=> 2

# Four different words, all making the one signal ---
["tm","mt","o","ttt"]
=> 1

# The longest signals, 48 symbols: 12 letters with 4-symbol codes.
