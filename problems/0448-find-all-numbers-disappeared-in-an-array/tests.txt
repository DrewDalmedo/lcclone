# Find All Numbers Disappeared in an Array. compare: unordered 0 accepts any
# order; the expected answers below list the numbers in increasing order.

@example n is 5, and 2 and 4 occur nowhere in nums.
[3,1,3,5,1]
=> [2,4]

@example Every integer from 1 to 4 occurs.
[2,1,4,3]
=> []

@example n is 2, so the values must be 1 or 2; 1 is missing.
[2,2]
=> [1]

# The smallest input.
[1]
=> []

# All entries equal: every other value is missing.
[4,4,4,4,4,4]
=> [1,2,3,5,6]

[1,1,1,1]
=> [2,3,4]

[5,5,5,5,5]
=> [1,2,3,4]

# Only 1 is missing.
[2,3,2]
=> [1]

# Only n is missing.
[1,2,3,1]
=> [4]

# 1 and n are both missing.
[3,2,3,2]
=> [1,4]

# A value occurring an even number of times is still present.
[2,2,1,1]
=> [3,4]

# And one occurring three times.
[2,2,2]
=> [1,3]

# Missing values in the middle.
[1,7,7,7,7,7,7]
=> [2,3,4,5,6]

# A permutation in decreasing order.
[6,5,4,3,2,1]
=> []

# Random small cases from gen.c (lc check --regen makes them).
@gen 1 small
[4,5,2,4,6,4,1]
=> [3,7]

@gen 2 small
[4,4,5,3,5]
=> [1,2]

@gen 3 small
[1,6,6,3,2,7,7,6]
=> [4,5,8]

@gen 4 small
[3,1,4,2]
=> []

@gen 5 small
[4,4,2,5,1,2]
=> [3,6]

@gen 6 small
[2,1]
=> []
