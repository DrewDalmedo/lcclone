# Minimum Absolute Difference Between Two Values. -1 means there is no
# pair of a 1 and a 2.

@example The only 1, at index 4, is 3 places from the 2 at index 1 and 4 places from the 2 at index 8; the nearer one counts.
[0,2,0,0,1,0,0,0,2]
=> 3

@example There is no 1, so there is nothing to measure.
[0,2,0,2,0]
=> -1

@example The 1 at index 6 is right next to the 2 at index 7.
[2,0,1,0,0,0,1,2]
=> 1

# A single entry never has a pair.
[0]
=> -1

[1]
=> -1

[2]
=> -1

# Neighbours, in both orders.
[1,2]
=> 1

[2,1]
=> 1

# All zeros; only 1s and zeros; only 2s and zeros.
[0,0,0,0]
=> -1

[1,0,1,1]
=> -1

[2,0,2,2]
=> -1
