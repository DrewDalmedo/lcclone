# Make Array Zero by Subtracting Equal Amounts.

@example Take away 2, then 5, then 4: the array becomes [5,0,5,0,0,9], then [0,0,0,0,0,4], then all zeros.
[7,2,7,0,0,11]
=> 3

@example Every entry is 0 already, so no round is needed.
[0,0]
=> 0

@example Take away 10, then 30. One round can't do it, since x is at most 10 in the first round.
[10,40]
=> 2

# A single positive entry, at the upper bound.
[100]
=> 1

# All entries equal and positive: one round.
[6,6,6,6]
=> 1

# Repeats far apart, with zeros among them: 0 is not a value to clear.
[3,0,8,3,0,8,0,3]
=> 2

# No zero and no repeat: one round per entry.
[5,1,4,2,3]
=> 5

# A run of zeros before the only positive value.
[0,0,0,1,0]
=> 1

# Large values far apart: 3 rounds, not 100 rounds of x = 1.
[100,50,99]
=> 3

# Zeros must stay at 0: lowering them too would make them negative.
[0,4]
=> 1

[2,0,2,5]
=> 2

# Values past 63 (too big for one 64-bit mask) and 100 next to 0.
[70,64,63,0,100,0,100]
=> 4

# One value, then zeros, then the same value again.
[9,0,0,0,0,0,0,0,0,9]
=> 1
