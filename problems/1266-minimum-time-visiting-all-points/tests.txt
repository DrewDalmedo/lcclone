# Minimum Time Visiting All Points.

@example Two diagonal moves and two moves along x reach (4,2) in 4 seconds; five moves down then reach (4,-3).
[[0,0],[4,2],[4,-3]]
=> 9

@example A single point: the token is already there.
[[-2,5]]
=> 0

@example (3,3) lies on the way from (1,1) to (5,5), but its turn comes after (5,5), so the token goes 4 diagonal moves out and 2 back.
[[1,1],[5,5],[3,3]]
=> 6

# The same point three times in a row costs nothing.
[[7,-7],[7,-7],[7,-7]]
=> 0

# A point repeated in the middle of the trip: the trip goes on after it.
[[1,2],[4,6],[4,6],[-2,0]]
=> 10

# Legs straight along y, then along x.
[[0,0],[0,9],[-6,9]]
=> 15

# Diagonal legs in all four directions, back to the start: 3 seconds
# each, though each leg covers 3 along x and 3 along y.
[[0,0],[3,3],[0,6],[-3,3],[0,0]]
=> 12

# Legs going left and down, one longer along x and one longer along y.
[[10,10],[2,7],[0,-1]]
=> 16

# One leg crossing both axes, from negative to positive coordinates.
[[-5,-2],[5,3]]
=> 10

# Moving 3 along x and 4 along y takes 4 seconds, not the straight-line
# distance 5.
[[0,0],[3,4]]
=> 4

# The order is fixed, though visiting 0, 1, 9, 10 in sorted order would
# take only 10 seconds.
[[0,0],[10,0],[1,0],[9,0]]
=> 27

[[2,2],[-3,4],[2,2],[-3,4]]
=> 15
