# The Two Sneaky Numbers of Digitville. compare: unordered 0 accepts the two
# numbers in either order; the expected answers below list the smaller first.

@example n = 6: each of 0 to 5 is there, and 1 and 5 appear twice.
[4,1,5,0,3,1,2,5]
=> [1,5]

@example n = 5: 0 can be one of the repeated numbers, here together with 4.
[4,1,0,4,2,3,0]
=> [0,4]

@example n = 2: both 0 and 1 must appear twice.
[1,0,1,0]
=> [0,1]

# The smallest n, in another order.
[1,1,0,0]
=> [0,1]

# n = 3, with the largest value repeated, and with 0 and the largest value.
[2,1,0,2,1]
=> [1,2]

[0,2,1,0,2]
=> [0,2]

# Each repeat right next to its twin.
[5,5,3,3,0,1,2,4]
=> [3,5]

# The first and the last entry repeat, far from their twins.
[3,0,1,2,4,5,6,1,3]
=> [1,3]

# 0 and n - 1 are the two repeats.
[0,7,1,2,3,4,5,6,7,0]
=> [0,7]

# Sorted, and sorted in reverse.
[0,1,1,2,3,3,4]
=> [1,3]

[4,3,2,2,1,0,0]
=> [0,2]
