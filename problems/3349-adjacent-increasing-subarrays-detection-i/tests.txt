# Adjacent Increasing Subarrays Detection I.

@example [4,6,9] and [1,3,8] are both strictly increasing, and the second starts right after the first. The drop from 9 to 1 between them doesn't matter.
[4,6,9,1,3,8,2]
3
=> true

@example The only stretches of six start at indices 0 and 1. Their front halves, [1,5,5] and [5,5,7], both repeat a 5, so neither cut works.
[1,5,5,7,9,10,2]
3
=> false

@example The whole array increases, so it splits into [-2,0] and [3,5].
[-2,0,3,5]
2
=> true

# The shortest array: with k = 1 any two neighbours work, even falling ones.
[3,-4]
1
=> true

# Equal values are never strictly increasing.
[7,7,7,7]
2
=> false

# A repeat inside a half spoils it.
[1,2,2,3,4,5]
3
=> false

# A repeat where the halves meet is allowed.
[1,2,3,3,4,5]
3
=> true

# A drop where the halves meet, and the halves fill the whole array.
[3,6,8,-1,0,2]
3
=> true

# Two runs of 3 that are long enough but not next to each other.
[1,2,3,0,5,4,6,7,8]
3
=> false

# One rising run of 2k - 1 elements is one short.
[1,2,3,4,5,0]
3
=> false

# One rising run of 2k elements at the end is enough on its own.
[9,8,1,2,3,4]
2
=> true

# One rising run of exactly 2k elements in the middle, with short runs on
# both sides of it.
[6,-1,2,3,5,7,8,4,4,0]
3
=> true

# The only stretch that works ends at the last element.
[5,4,3,1,2,0,7]

=> true

# A run of 2 next to a run of 5: neither split gives two halves of 3.
[1,2,0,1,2,3,4]
