# Middle of the Linked List. The result is the list from the middle node to
# the tail.

@example Seven nodes: 9 has three nodes on each side.
[2,7,4,9,3,8,6]
=> [9,3,8,6]

@example Four nodes: 1 and 8 share the center, and 8 is the later one.
[5,1,8,6]
=> [8,6]

@example One node is its own middle.
[9]
=> [9]

# Two nodes: the second.
[3,6]
=> [6]

# Three nodes.
[10,20,30]
=> [20,30]

# Equal values: only the length of the result tells the nodes apart.
[4,4,4,4]
=> [4,4]

# Equal values, odd length.
[4,4,4,4,4]
=> [4,4,4]

# Seven nodes, alternating, with both value limits.
[100,1,100,1,100,1,100]
=> [1,100,1,100]

# Six nodes.
[11,12,13,14,15,16]
=> [14,15,16]

@gen 1 small
[3,1,2,2,1,4,4]
=> [2,1,4,4]

@gen 2 small
[1,1,1,1,1]
=> [1,1,1]

@gen 3 small
[3,1,3,1,4,2,2,3]
=> [4,2,2,3]

@gen 4 small
[3,2,1,3]
=> [1,3]

@gen 5 small
[2,2,3,4,4,3]
=> [4,4,3]
