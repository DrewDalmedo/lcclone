# Uncommon Words from Two Sentences. compare: unordered 0 accepts the words
# in any order; the expected answers below list them in the order they
# first appear, s1 before s2.

@example "the" occurs twice in s1, and "cat" once in each sentence; every other word occurs once in the two together.
"the cat sat on the mat"
"a cat ran"
=> ["sat","on","mat","a","ran"]

@example Every word occurs once in each sentence, so none is uncommon.
"same words here"
"here same words"
=> []

@example "x" and "xy" are different words, each occurring once.
"x"
"xy"
=> ["x","xy"]

# Single words, the same.
"a"
"a"
=> []

# A word twice in one sentence and absent from the other is not uncommon.
"hi there hi"
"bye"
=> ["there","bye"]

# Once in each sentence is not uncommon either.
"moon"
"moon sun"
=> ["sun"]

# Every word differs from every other: all are uncommon.
"ab cd"
"ef gh ij"
=> ["ab","cd","ef","gh","ij"]

# Identical sentences.
"one two three"
"one two three"
=> []

# Prefixes and suffixes of a word are other words.
"car cart art"
"carts ar"
=> ["car","cart","art","carts","ar"]

# The repeats are all in s2.
"lone"
"dup dup lone"
=> []

# A word three times across both sentences.
"x y x"
"x z"
=> ["y","z"]

# Ten one-letter words in each sentence; only a and k are not shared.
"a b c d e f g h i j"
"j i h g f e d c b k"
=> ["a","k"]

# Longest sentences: one word of 200 letters, and the word b 100 times.
"aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"
"b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b b"
=> ["aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"]
