# Check if Array is Good.

@example Put in order, it reads 1, 2, 3, 4, 5, 5.
[4,2,5,1,3,5]
=> true

@example Five elements would have to be 1, 2, 3, 4, 4, but there is no 1 and 3 appears twice.
[3,4,2,4,3]
=> false

@example One element is never good, not even 1: the shortest good array has two.
[1]
=> false

# The shortest good array: k = 1.
[1,1]
=> true

# Two elements must be 1 and 1.
[2,2]
=> false

[1,2]
=> false

# k = 2, with the two copies of 2 apart.
[2,1,2]
=> true

# k = 6, with the copies of 6 at both ends.
[6,3,5,1,6,2,4]
=> true

# 5 is the largest value, but k = 5 would need six elements.
[2,5,3,1,4]
=> false

# 3 appears only once, and 1 twice.
[1,3,2,1]
=> false

# 3 appears three times, and 2 not at all.
[3,3,1,3]
=> false

# The same length, sum and largest value as 1, 2, 3, 4, 4, with 4 twice,
# but 1 and 3 became two more copies of 2.
[4,2,2,4,2]
=> false

# The same length, sum, bitwise XOR and largest value as 1, 2, 3, 4, 5, 6, 6,
# with 6 twice, but 3 and 4 became a second 2 and a second 5.
[2,6,5,1,5,6,2]
=> false

# A value of 200, far above the length.
[1,200,1]
=> false

# The longest good array: 1 to 98 once, and 99 at both ends.

=> true
