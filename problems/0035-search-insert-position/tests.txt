# Search Insert Position.

@example 9 is in the list, at index 3.
[-4,0,3,9,12]
9
=> 3

@example -9 is not in the list; it would go between -15 and -6, at index 1.
[-15,-6,8]
-9
=> 1

@example 4 is larger than every element, so it would go after the last one, at index 3, the length of the list.
[-7,-5,-1]
4
=> 3

# Between two negative values.
[-50,-30,-10,20]

=> 2

# Between two elements of a list of two.

=> 1

# Consecutive values, target just past the middle.

=> 5

# Between the last two elements.
[3,7,13,21]

=> 3
