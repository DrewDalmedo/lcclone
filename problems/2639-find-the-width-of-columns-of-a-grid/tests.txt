# Find the Width of Columns of a Grid. The answer lists the widths in
# column order.

@example Column 0's longest number is -305, four characters; in column 1, 12 and -4 tie at two.
[[-305,7],[88,12],[0,-4]]
=> [4,2]

@example With one row, each width is the length of its only number: 0 takes one character, -1 two and 10^9 ten.
[[0,-1,1000000000]]
=> [1,2,10]

@example -640 is the smallest number of the column but the widest, at four characters.
[[512],[-640],[99]]
=> [4]

# A single zero is one character wide.
[[0]]
=> [1]

# A column of zeros only is 1 wide.
[[0,5],[0,-5],[0,0]]
=> [1,2]

# The widest possible number, -10^9, is 11 characters.
[[-1000000000],[1000000000],[999999999]]
=> [11]

# The bounds and their neighbours in one row.
[[1000000000,-1000000000,999999999,-999999999]]
=> [10,11,9,10]

# Every boundary between digit counts, positive and negative.
[[9,99,999,9999,99999],[10,100,1000,10000,100000]]
=> [2,3,4,5,6]

[[999999,9999999,99999999],[1000000,10000000,100000000]]
=> [7,8,9]

[[-9,-99,-999],[-10,-100,-1000]]
=> [3,4,5]

# The sign counts: -3 beats 3, -42 ties with 310, and -123 beats 700.
[[3,-42,700],[-3,310,-123]]
=> [2,3,4]

# The widest number is in the first row, the middle or the last row; in

[[-5000,1,2,11,-1],[10,20,30,22,-2],[7,8,-900,33,-3]]
=> [5,2,4,2,2]

# More rows than columns.
[[1,-1],[12,-12],[123,-123],[1234,-1234]]
