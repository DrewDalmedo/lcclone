# Power of Four.

@example 1024 = 4^5, written 100000 in base 4.
1024
=> true

@example 128 = 2^7 is a power of two, but with an odd exponent: it lies between 4^3 = 64 and 4^4 = 256.
128
=> false

@example 80 = 64 + 16 is written 1100 in base 4, with two 1s.
80
=> false

# Zero has no bit set, so n & (n - 1) == 0 alone lets it through.

=> false
