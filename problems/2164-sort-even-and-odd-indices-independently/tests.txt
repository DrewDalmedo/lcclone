# Sort Even and Odd Indices Independently.

@example The red positions 0, 2, 4 hold 5, 3, 1, which become 1, 3, 5; the blue positions 1, 3, 5 hold 2, 8, 6, which become 8, 6, 2.
[5,2,3,8,1,6]
=> [1,8,3,6,5,2]

@example With an odd length the last position is red: 6, 4, 2 become 2, 4, 6, and 1, 5 become 5, 1.
[6,1,4,5,2]
=> [2,5,4,1,6]

@example A single number has nothing to trade places with.
[7]
=> [7]

# Two numbers: one red, one blue, so nothing moves.
[10,20]
=> [10,20]

[100,1]
=> [100,1]

# Three numbers: only one blue position.
[9,4,1]
=> [1,4,9]

# All equal.
[5,5,5,5]
=> [5,5,5,5]

# Already arranged.
[1,9,2,8,3,7]
=> [1,9,2,8,3,7]

# Each color starts in the opposite of its final order.
[6,1,5,2,4,3]
=> [4,3,5,2,6,1]

# The large numbers are all red and stay red.
[100,1,99,2,98,3]
=> [98,3,99,2,100,1]

# Repeated values within each color, odd length.
[2,7,2,7,1,3,1]
=> [1,7,1,7,2,3,2]

# The bounds of the values.
[100,1,1,100]
=> [1,100,100,1]

# The last red number moves to the front.
[50,10,40,20,30]
=> [30,20,40,10,50]
