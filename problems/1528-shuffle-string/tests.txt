# Shuffle String.

@example n goes to 3, i to 2, g to 4, h to 1 and t to 0.
"night"
[3,2,4,1,0]
=> "thing"

@example p goes to 1, e to 2 and n to 0. Taking the letter at indices[i] for position i would give "enp" instead.
"pen"
[1,2,0]
=> "npe"

@example Repeated letters move like any others: x goes to 2, the two z's to 4 and 1, the y's to 0 and 3.
"xyzzy"
[2,0,4,1,3]
=> "yzxyz"

# A single letter.
"q"
[0]
=> "q"

# Nothing moves.
"plain"
[0,1,2,3,4]
=> "plain"

# Full reversal.
"stressed"
[7,6,5,4,3,2,1,0]
=> "desserts"

# Neighbours swap places.
"abcdef"
[1,0,3,2,5,4]
=> "badcfe"

# Every letter moves one place right, and the last wraps to the front.
"abcdef"
[1,2,3,4,5,0]
=> "fabcde"

# Every letter moves one place left, and the first wraps to the end.
"abcdef"
[5,0,1,2,3,4]
=> "bcdefa"

# A cycle of three among repeated letters.
"aab"
[1,2,0]
=> "baa"

# All one letter.
"kkkk"
[2,0,3,1]
=> "kkkk"

# The first and last letters of the alphabet.
"zay"
[2,0,1]
=> "ayz"
