# Binary Tree Tilt. A case is the tree in level order, with null for an
# absent child; the result is the sum over all nodes of the absolute
# difference between the totals of their two subtrees.

@example Node -2 has pans 1 and 0, tilt 1. The root has pans -1 and 3, tilt 4. The leaves add nothing.
[5,-2,3,1]
=> 5

@example Node 6 has pans -3 and 2, tilt 5. The root has an empty left pan and 5 on its right, tilt 5.
[4,null,6,-3,2]
=> 10

# An empty tree.
[]
=> 0

# A lone node.
[7]
=> 0

# Only a left child.
[3,8]
=> 8

# Only a right child, negative.
[3,null,-8]
=> 8

# Whole subtrees count, not just the children: 7 + |12 - 1|.
[2,5,1,7]
=> 18

# A node's own value is on neither side: the root's pans are 5 and 5.
[1000,3,5,2]
=> 2

# Subtrees of opposite signs: 1 + |-5 - 6|.
[0,-4,6,null,-1]
=> 12

# Both negative: 1 + |-5 - -3|, where the root adds 2, not 8.
[0,-4,-3,-1]
=> 3

# A subtree of large values whose total cancels to 0.
[0,-1000,7,1000,0]
=> 1007

# A path of the lowest value: 1000 + 2000.
[-1000,-1000,null,-1000]
=> 3000

# Alternating signs along a path: subtree totals -5, 0, -5.
[5,-5,null,5,null,-5]
=> 10

# Single children on alternating sides: 6 + 8 + 11.
[10,null,3,2,null,null,6]
=> 25
