# Count Negative Numbers in a Sorted Matrix.

@example The negative cells are -1 and -3 in the middle row and the whole bottom row.
[[5,2,0],[2,-1,-3],[-2,-2,-4]]
=> 5

@example Zeros are not negative; only the -6 in the bottom-right corner is.
[[1,0],[0,0],[0,-6]]
=> 1

@example A single column: everything below the 6 is negative.
[[6],[-3],[-8]]
=> 2

# A single cell: zero, then the lowest allowed value.
[[0]]
=> 0

[[-100]]
=> 1

# Every cell is negative: the answer is m * n.
[[-1,-1,-2],[-3,-4,-5]]
=> 6

# No negatives at all, though zeros are plentiful.
[[2,1,0],[1,0,0],[0,0,0]]
=> 0

# The top rows have no negatives; only the bottom row does.
[[8,6,5],[4,4,1],[0,0,0],[-1,-9,-9]]
=> 3

# Zeros right before the negative block, which grows by one cell per row.
[[0,0,-1],[0,-1,-1],[-1,-1,-1]]
=> 6

# Identical rows, with the same negative value repeated across the boundary.
[[3,-2,-2],[3,-2,-2],[3,-2,-2]]
=> 6

# Far from square: 2 x 9 and 9 x 2.
[[7,5,5,3,1,0,0,-1,-4],[2,2,0,0,-1,-1,-3,-3,-8]]
=> 7

[[4,1],[3,0],[3,0],[2,-1],[1,-1],[0,-2],[0,-5],[-1,-5],[-6,-9]]
=> 8
