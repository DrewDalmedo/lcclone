# Remove Duplicates from Sorted Array. check: prefix nums, so each expected
# result is the first k elements of nums after the call, in order.

@example The distinct values are -4, 0, 3 and 8, so k = 4. What nums holds after them doesn't matter.
[-4,-4,0,3,3,3,8]
=> [-4,0,3,8]

@example Every element is 6, so k = 1.
[6,6,6,6]
=> [6]

@example No value repeats: k = 3, and nums can stay as it is.
[-2,1,5]
=> [-2,1,5]

# A single element.
[0]
=> [0]

# Two elements, equal and different.
[50,50]
=> [50]

[-1,0]
=> [-1,0]

# A run of repeats at the start.
[-7,-7,-7,-1,4,9]
=> [-7,-1,4,9]

# A run of repeats at the end.
[2,5,11,11,11,11]
=> [2,5,11]

# A long run in the middle.
[1,2,2,2,2,2,2,2,3]
=> [1,2,3]

# Every value twice, so every kept value but the first moves.
[-3,-3,0,0,1,1,2,2]
