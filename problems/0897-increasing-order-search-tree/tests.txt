# Increasing Order Search Tree. A case is the tree in level order; the result
# is the ladder of the same values, smallest on top, down right children.

@example Read in order, the tree holds 1, 3, 6, 8, 11.
[8,3,11,1,6]
=> [1,null,3,null,6,null,8,null,11]

@example The root stays on top, and 25 moves up between it and 30.
[20,null,30,25]
=> [20,null,25,null,30]

@example A chain of left children turns upside down.
[9,4,null,2]
=> [2,null,4,null,9]

# One node, holding the smallest value allowed.
[0]
=> [0]

# One node, holding the largest value allowed.
[1000]
=> [1000]

# Already a ladder: nothing moves.
[2,null,4,null,7]
=> [2,null,4,null,7]

# A longer left path: every link reverses.
[7,6,null,4,null,3,null,1]
=> [1,null,3,null,4,null,6,null,7]

# A zigzag path.
[50,10,null,null,40,20]
=> [10,null,20,null,40,null,50]

# The root is the smallest value, with a full subtree on its right.
[10,null,30,20,40]
=> [10,null,20,null,30,null,40]

# The root is the largest value: it ends up as the childless last rung.
[1000,500,null,null,700]
=> [500,null,700,null,1000]

# Value 0 is a real node and becomes the top.
[6,2,9,0]
=> [0,null,2,null,6,null,9]

# A complete tree of three levels.
[44,21,63,12,35,52,78]
=> [12,null,21,null,35,null,44,null,52,null,63,null,78]

# A left subtree with its own right branch: no left link may survive.
[8,2,null,1,5,null,null,4,7]
=> [1,null,2,null,4,null,5,null,7,null,8]
