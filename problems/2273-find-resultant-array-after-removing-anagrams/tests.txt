# Find Resultant Array After Removing Anagrams. The words kept are written
# as they were spelled in words, in their original order.

@example tar and art are removed as anagrams of the word before them, and so are tsar and rats. star has one letter more than art, so it stays.
["rat","tar","art","star","tsar","rats","ant"]
=> ["rat","star","ant"]

@example study is removed. night and thing are anagrams, and so are the two dusty, but in each pair the two words are never neighbours.
["dusty","study","night","dusty","thing"]
=> ["dusty","night","dusty","thing"]

@example An identical word is an anagram, and so is mono. noon has two n's where moon has an m and an n.
["moon","moon","mono","noon"]
=> ["moon","noon"]

# A single word.
["z"]
=> ["z"]

# Every word the same.
["aa","aa","aa","aa"]
=> ["aa"]

# The same letters in different numbers are not anagrams.
["aab","abb","bab"]
=> ["aab","abb"]

# Different lengths with the same set of letters, the longer word first and
# then the shorter one first: a check that one word's letters are among the
# other's, in either direction, is not enough.
["aabb","ab","ba","abab","bbaa"]
=> ["aabb","ab","abab"]

# Letters at the end of the alphabet: zzy and zyy differ in their counts.
["zzy","yzz","zyy","xyz"]
=> ["zzy","zyy","xyz"]

# Equal sums of letter codes (ad, bc) and equal XORs (aa, bb), but no
# anagrams.
["ad","bc","aa","bb"]
=> ["ad","bc","aa","bb"]

# Two anagram classes taking turns: nothing is removed.
["ab","cd","ba","dc","ab"]
=> ["ab","cd","ba","dc","ab"]

# The first word of a run stays, not the last, spelled as it was.
["tea","eat","ate"]
=> ["tea"]

# Two runs: comparing with the first word only would keep dc.
["ab","ba","cd","dc"]
=> ["ab","cd"]

# A run of five anagrams, then another word.
["abc","bca","cab","bac","acb","x"]
=> ["abc","x"]
