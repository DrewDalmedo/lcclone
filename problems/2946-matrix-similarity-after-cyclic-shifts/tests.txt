@example Both rows have 3 columns, so after 3 ticks every value has gone once round its ring and is back where it started.
[[4,7,9],[2,5,2]]

=> true

@example Row 0 repeats every 2 columns, so 2 ticks leave it as it was; but row 1, moved 2 places right, reads [5,1,5,5,1,5].

2
=> false

@example Both rows repeat every 3 columns. 9 ticks move each row 9 places, which is the same as 3 places, and that changes nothing.

=> true

# k is a multiple of n (k = 2n): true although no row repeats.

=> true

# k = 50 is far past n = 3: k mod 3 = 2 and gcd(50, 3) = 1, so only
# constant rows come back. For the odd row, (j - k) % n is negative here.
[[6,6,6],[2,2,2],[9,9,9]]
50
=> true

# The same, but one value of the last row, an odd one, is different.
[[6,6,6],[2,2,4]]
50
=> false

# n = 6, k = 4: rows that repeat every 2 columns come back, though k is
# not a multiple of n and one tick would change them.
[[1,8,1,8,1,8],[4,10,4,10,4,10]]

=> true
